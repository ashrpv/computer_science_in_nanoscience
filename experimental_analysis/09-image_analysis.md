Цель: получить размеры, форму и доли фаз в физических единицах, описав выбор полей зрения, правила сегментации и устойчивость результата. Примеры выполняются последовательно; вместо внешней микрофотографии используется явно искусственное изображение.

## 1. Масштабная калибровка и съёмка

Если масштабная линейка длиной `L` занимает `N` пикселей, размер пикселя `s = L/N`. Для изотропного изображения:

$$L_{phys}=L_{px}s,\qquad A_{phys}=A_{px}s^2,\qquad P_{phys}=P_{px}s.$$

При малой относительной неопределённости масштаба 2% её вклад составляет примерно 2% в длину, 4% в площадь и 6% в объём. Это вклад калибровки, не полная неопределённость сегментации. Для разных шагов по осям используют отдельные `s_x`, `s_y`; для 3D дополнительно `s_z`.

После изменения размера изображения масштаб меняется. Его фиксируют для каждого режима камеры и увеличения. При съёмке контролируют фокус, экспозицию, насыщение, освещение, геометрию и битность. Масштабную линейку и подписи исключают из области анализа по заданному правилу.

## 2. Выборка: образцы, поля зрения и объекты

Иерархия обычно выглядит так: независимый образец → поля зрения → объекты. Координаты полей выбирают случайно или систематически по заранее заданной схеме. Тысячи частиц в одном кадре не заменяют несколько независимых образцов.

Поле зрения — единица отбора внутри образца, но не обязательно независимая единица для сравнения воздействий. Вывод о технологии опирается на уровень назначения воздействия: образец, партию или иной объект дизайна. Указывают отдельно число образцов, полей и объектов.

## 3. Предобработка, порог и морфология

Выбор канала, коррекция фона и подавление шума должны сохранять интересующие объекты. Сильная коррекция фона может стереть крупные частицы или поры.

Otsu выбирает глобальный порог по гистограмме. При неравномерном освещении нужен локальный порог, коррекция фона или другая модель. Знак сравнения зависит от полярности: светлые объекты — `image > threshold`, тёмные — `image < threshold`.

| Операция | Что меняет | Возможное искажение |
|---|---|---|
| Удаление мелких компонент | Отбрасывает области ниже заданной площади | Теряет реальные мелкие частицы |
| Заполнение отверстий | Убирает малые отверстия внутри объекта | Уменьшает измеряемую пористость |
| Opening | Убирает тонкие выступы и перемычки | Меняет контур |
| Closing | Соединяет близкие разрывы | Объединяет объекты |

Размеры операций переводят из физических единиц в пиксели. Выбор связности 4 или 8 в 2D влияет на соединение диагональных пикселей. Карта границ показывает переходы яркости, но для площади нужна заполненная маска объекта.

## 4. Маска и watershed: пример

Пример использует API scikit-image 0.25.2 из файла зависимостей. `min_area_um2` — минимальная площадь объекта, `marker_distance_um` — расстояние между маркерами.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import ndimage as ndi
from skimage import filters, morphology, measure, feature, segmentation, draw

rng = np.random.default_rng(42)
image = np.zeros((160, 200), dtype=float)
for center, radius in [((50, 55), 19), ((50, 85), 19), ((112, 142), 16)]:
    rr, cc = draw.disk(center, radius, shape=image.shape)
    image[rr, cc] = 1.0
image = np.clip(ndi.gaussian_filter(image, 1) + rng.normal(0, 0.02, image.shape), 0, 1)
s = 0.2  # мкм/px для учебного изображения
params = {"min_area_um2": 1.0, "hole_area_um2": 0.5,
          "marker_distance_um": 2.0, "threshold_offset": 0.0}

def segment(image, s, params):
    if image.ndim != 2 or not np.isfinite(image).all() or s <= 0:
        raise ValueError("Нужно конечное 2D-изображение и положительный масштаб")
    if image.max() == image.min():
        raise ValueError("Изображение не содержит контраста")
    threshold = filters.threshold_otsu(image) + params["threshold_offset"]
    mask = image > threshold
    min_px = max(1, int(np.ceil(params["min_area_um2"] / s**2)))
    hole_px = max(1, int(np.ceil(params["hole_area_um2"] / s**2)))
    mask = morphology.remove_small_objects(mask, min_size=min_px, connectivity=2)
    mask = morphology.remove_small_holes(mask, area_threshold=hole_px, connectivity=2)
    distance = ndi.distance_transform_edt(mask)
    coords = feature.peak_local_max(
        distance, labels=mask, exclude_border=False,
        min_distance=max(1, int(np.ceil(params["marker_distance_um"] / s))),
    )
    if len(coords) == 0:
        raise ValueError("Не найдены маркеры объектов")
    markers = np.zeros(mask.shape, dtype=int)
    markers[tuple(coords.T)] = np.arange(1, len(coords) + 1)
    labels_all = segmentation.watershed(
        -distance, markers, mask=mask, connectivity=np.ones((3, 3), dtype=bool)
    )
    # Явное учебное правило: исключаем объекты, касающиеся границы кадра.
    labels = segmentation.clear_border(labels_all)
    labels = morphology.remove_small_objects(labels, min_size=min_px)
    return mask, labels, threshold

mask, labels, threshold = segment(image, s, params)
fig, axs = plt.subplots(1, 3, figsize=(10, 3), layout="constrained")
for ax, values, title in zip(axs, [image, mask, labels], ["Исходное", "Маска", "Объекты"]):
    ax.imshow(values, cmap="gray" if title != "Объекты" else "tab20")
    ax.set(title=title)
    ax.set_axis_off()
plt.show()
```

Watershed разделяет маску по маркерам на рельефе отрицательного расстояния. Избыток маркеров дробит частицу, недостаток объединяет соседние. Метод не восстанавливает достоверно скрытый контур при сильном перекрытии в проекции. Маркеры и маски проверяют на ручной разметке.

Исключение объектов у края может смещать распределение против крупных объектов. Для количественной работы заранее выбирают подходящее правило рамки отбора и оценивают его влияние. В примере полная маска сохраняется отдельно от меток принятых объектов.

## 5. Таблица измерений

```python
properties = measure.regionprops_table(
    labels, spacing=(s, s),
    properties=("label", "area", "perimeter", "equivalent_diameter_area",
                "axis_major_length", "axis_minor_length", "eccentricity", "solidity"),
)
objects = pd.DataFrame(properties).assign(sample_id="S001", field_id="F001")
objects["circularity"] = 4 * np.pi * objects["area"] / objects["perimeter"]**2
objects["aspect_ratio"] = objects["axis_major_length"] / objects["axis_minor_length"]
print(objects[["label", "area", "equivalent_diameter_area", "circularity"]])
```

`spacing` уже переводит геометрические величины в физические единицы: повторно умножать площадь на `s²` не нужно. Пример периметра рассчитан на одинаковый масштаб по двум осям. Для анизотропных пикселей проверяют поддержку конкретного свойства.

| Признак | Определение | Ограничение |
|---|---|---|
| Эквивалентный диаметр | $d_{eq}=\sqrt{4A/\pi}$ | Диаметр равновеликого круга, не 3D-размер |
| Circularity | $4\pi A/P^2$ | Сильно зависит от оценки периметра |
| Aspect ratio | `major / minor` | Оси эквивалентного эллипса |
| Eccentricity | Эксцентриситет | Безразмерная характеристика формы |
| Solidity | Площадь / площадь выпуклой оболочки | Чувствительность к вогнутостям |

Пикселизация и метод оценки периметра влияют на круглоту; значения могут отличаться от идеальной геометрии. Сравнивать серии следует при сопоставимых разрешении и правилах обработки. Для вырожденных объектов проверяют нулевые периметр и малую ось.

Размеры описывают распределением: медианой, квантилями, числом объектов и правилом отсечения. Среднее по всем частицам может скрывать различия между полями и образцами.

## 6. Пористость и дефектность

Площадная доля пор $\phi_A=A_{pore}/A_{ROI}$. Нужно явно определить поры и область интереса; подписи, артефакты и края исключают согласованно. Маска из примера выделяет светлые частицы, поэтому её долю нельзя без переопределения назвать пористостью.

Переход от 2D-доли к объёмной требует обоснованного стереологического отбора и репрезентативных сечений. Из одного изображения поверхности нельзя автоматически получить объёмную пористость или различить открытые и закрытые поры.

Для дефектности можно считать число дефектов на площадь, долю их площади, распределение размеров и расстояния. Класс дефекта задают до анализа и проверяют вручную.

## 7. Устойчивость и иерархическая неопределённость

Варьируют допустимые порог, минимальную площадь, расстояние маркеров и правила края. Ищут диапазон, в котором сохраняются научные выводы, а не параметр с удобным результатом.

```python
rows = []
for offset in [-0.03, 0.0, 0.03]:
    for min_area in [0.5, 1.0, 2.0]:
        changed = {**params, "threshold_offset": offset, "min_area_um2": min_area}
        _, current, _ = segment(image, s, changed)
        table = pd.DataFrame(measure.regionprops_table(
            current, spacing=(s, s), properties=("label", "equivalent_diameter_area")
        ))
        rows.append({"offset": offset, "min_area_um2": min_area,
                     "n_objects": len(table),
                     "median_diameter_um": table["equivalent_diameter_area"].median()})
print(pd.DataFrame(rows))
```

Повторный запуск на том же изображении оценивает алгоритмическую часть, не вариацию материала. Для обобщения учитывают структуру $y_{ijk}=\mu+sample_i+FOV_{j(i)}+\varepsilon_{ijk}$. В иерархическом bootstrap сначала выбирают независимые образцы, затем поля внутри них; число пикселей не является размером независимой выборки.

## 8. Пакетная обработка и мини-проект

Для каждого поля сохраняют исходное изображение, масштаб, полную маску, метки объектов, таблицу свойств и QC. Метки одного поля уникальны только вместе с `sample_id` и `field_id`. В таблице полей отдельно фиксируют даже кадры с нулём объектов и неуспешные обработки; иначе они исчезнут из статистики серии.

Цикл по файлам выполняет одну и ту же функцию `segment`, получает масштаб и ID из реестра и записывает параметры с версией кода. Сводный QC включает насыщение, долю объектов у края, число маркеров и примеры наложения контуров на исходник.

Мини-проект: сравнить несколько полей независимых образцов, обосновать калибровку и выбор координат, получить распределения размеров и карту устойчивости параметров. Отдельно указать число образцов, полей, принятых и исключённых объектов, а также причину исключения.
