# Пять реальных микрофотографий: цвет, контраст и размеры

Исходные JPEG предоставлены для [практикума к лекции 9](../../09-microscopy-homework.md). Каждый файл служит **характерным примером своего случая обработки**, а не случайным полем зрения общей серии. `1a.JPG` и `1b.jpg` относятся к случаю пигментных частиц; их принадлежность к одному физическому образцу не подтверждена. Изображения сохранены побайтно без изменения цвета, контраста, кадрирования и подписей.

| ID | Исходный файл | Наблюдение и назначение | Линейка в JPEG |
|---|---|---|---|
| P01 | [`1a.JPG`](raw/1a.JPG) | Цветные пластинчатые пигментные частицы; маски внутренних областей и неоднородность цвета | Нет |
| P02 | [`1b.jpg`](raw/1b.jpg) | Пигментный объект с неровным краем, неоднородной освещённостью и затемнением справа; устойчивость оценки цвета | 100 мкм |
| N01 | [`2016-02-26-n1-1-4.jpg`](raw/2016-02-26-n1-1-4.jpg) | Плотно расположенные огранённые наночастицы; трудные наложения и границы применимости автоматического разделения | 100 нм |
| N02 | [`2019-02-18-2-6035.jpg`](raw/2019-02-18-2-6035.jpg) | Округлые объекты с неоднородным контрастом; сравнение предобработки и качества границ | 0,5 мкм |
| N03 | [`2019-12-13-9-2.jpg`](raw/2019-12-13-9-2.jpg) | Тёмные округлые силуэты; автоматическая сегментация и распределение размеров в одном поле | 500 нм |

`manifest.csv` содержит пути, размеры в пикселях, надписи линеек, сведения о способе съёмки **с указанием степени подтверждения** и SHA-256 точных байтов. `verify.py` проверяет исходные файлы по реестру. Из корня репозитория:

```bash
python experimental_analysis/data/microscopy_examples/verify.py
```

## Что известно и чего нет

- P01 и P02 выглядят как световые микрофотографии. Для N02 режим `SEI` указан в самой подписи СЭМ-снимка. N01 и N03 выглядят как ПЭМ, но способ съёмки для этих двух файлов не подтверждён отдельным протоколом; в реестре стоит `TEM_probable`.
- В каждом JPEG есть профиль **sRGB** для интерпретации кодированных цветов файла; сведений о калибровке камеры, экспозиции, балансе белого, источнике света, референтной цветовой мишени и исходном приборном файле нет. Отсутствует EXIF с дополнительными условиями съёмки. Профиль JPEG не калибрует цвет пигмента как материала.
- Масштабные надписи прочитаны непосредственно на изображениях. Число пикселей в линейке и мкм/пиксель или нм/пиксель **не записаны как исходные приборные значения**: студент определяет их на копии JPEG и описывает погрешность границ линейки. Для P01 физических единиц пока нет.
- Нет достоверных связей `sample_id → image_id`, числа независимо приготовленных образцов, плана выбора полей зрения и условий приготовления. Имя файла, дата и надписи СЭМ-снимка не заменяют эти сведения. Нельзя считать P01 и P02 техническими повторами или связывать N01/N03 с [таблицей измерений магнетита](../tem_magnetite/README.md).
- По изображениям можно описывать цвет **сохранённого изображения**, форму двумерной проекции и измерения в выбранном поле. Материал, кристаллическую фазу, цвет порошка при стандартном освещении, трёхмерные размеры и распределение по генеральной совокупности по одному JPEG не устанавливают.

## Работа с исходниками

Для анализа храните `raw/` неизменным. Маски, исправленные копии, таблицы измерений и параметры предобработки сохраняйте отдельно. Линейки, подписи, круговые чёрные края, затемнённые области и объекты на границе следует помечать до расчёта признаков. При изменении размера JPEG пересчитывайте масштаб. Сопоставлять с [данными отражения](../../08-spectra_and_curves.md) можно только после подтверждения идентичности физических образцов и условий наблюдения.
