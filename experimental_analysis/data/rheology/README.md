# Реологические кривые наноэмульсии

Обезличенная учебная выгрузка из реальных лабораторных измерений. Файлы предназначены для заданий по [организации экспериментальных данных](../../../experimental_data/05-homework.md) и [анализу кривых](../../08-homework.md). Исходная лабораторная книга не публикуется: в наборе оставлены измеренные величины и необходимые для анализа связи между образцами, а идентифицирующие подписи и календарные даты удалены. Это **преобразованный широкий экспорт**, а не неизменённый файл прибора.

## Устройство опыта

- Все шесть физических образцов относятся к **одной партии** `B01`. Для каждого измерения брали отдельный образец (`P01`–`P06`); один запуск прибора (`R01`–`R06`) приходится на один образец. Разные уровни состава представлены образцами этой общей партии, а не независимыми приготовленными партиями.
- Все образцы прошли одинаковую лабораторную обработку и термостатирование. Использована стандартная для лаборатории геометрия «цилиндр в цилиндре». Детальные размеры геометрии и закрытые части протокола в учебном наборе не раскрываются. Фактическая температура сохранена для каждой точки.
- `formulation_id` кодирует уровни обезличенной добавки; `level_pct` сохраняет процентные уровни 0; 0,25; 0,5; 0,75. Химическое наименование не является частью открытого набора.
- `session_id` сохраняет известное различие дней без календарных дат: `R01` получена в сеансе `A`, остальные пять серий — в сеансе `B`. Поэтому сравнение уровня 0 с другими уровнями смешано с различием сеансов.
- `step_s` — номинальный шаг программы: 3 или 6 секунд на точку. Значения времени фактически измерены и оставлены отдельными столбцами. Два запуска при 0,25 % и два при 0,75 % сделаны на **разных образцах** одной партии; это не повторные измерения одного образца и не независимые партии.

## Файлы и ключи

| Файл | Одна строка | Содержание |
|---|---|---|
| [`specimens.csv`](specimens.csv) | Один запуск / отдельный образец | `run_id`, `specimen_id`, общая `batch_id`, код и уровень состава, шаг, сеанс |
| [`viscosity_wide.csv`](viscosity_wide.csv) | Совместный номер точки в шести сериях | Для каждого `R01`–`R06` семь колонок с префиксом запуска |

Широкий файл содержит 200 строк и 42 колонки, по 200 точек на запуск. Поле `Rxx_point_id` имеет вид `1|1`…`1|100` для прохода с увеличением скорости сдвига и `2|1`…`2|100` для обратного хода. На границе проходов скорость 1000 с⁻¹ встречается дважды; это **две последовательные точки**, а не дублирующийся ID. При преобразовании в длинную таблицу ключ — `run_id × направление × номер точки`.

| Суффикс колонки после `Rxx_` | Смысл | Единица |
|---|---|---|
| `point_id` | Номер прохода и точки в исходном экспорте | — |
| `shear_rate_s_inv` | Скорость сдвига | с⁻¹ |
| `stress_Pa` | Напряжение сдвига | Па |
| `viscosity_Pa_s` | Кажущаяся вязкость | Па·с |
| `temperature_C` | Измеренная температура | °C |
| `elapsed_s` | Время от начала записи запуска | с |
| `segment_s` | Время внутри текущего прохода; сбрасывается при переходе ко второму | с |

Скорость меняется приблизительно от 0,1 до 1000 с⁻¹. Исходные числовые показания перенесены без сглаживания, удаления и подстановок. Вязкость согласуется с `stress_Pa / shear_rate_s_inv` с точностью до округления. В последней точке `R01` при малой скорости записаны нулевые напряжение и вязкость; причина в опубликованном наборе не установлена. Отметьте точку в журнале контроля качества, не исправляйте её без первичной записи.

## Как работать с набором

Читайте оба CSV из корня репозитория; доступных для курса `pandas` и стандартных библиотек достаточно. Преобразуйте широкий файл в одну строку на точку, добавьте поля `run_id`, `specimen_id`, `batch_id`, `formulation_id`, `level_pct`, `step_s`, `session_id`, `sweep`, `point_no` и `source_row`. `source_row` — номер строки широкого CSV, начиная с 2 для первой записи. Не объединяйте одноимённые `point_id` разных запусков и не теряйте оригинальный широкий файл.

Контрольные числа: шесть запусков, шесть отдельных образцов, **одна партия**, по 100 точек каждого направления на запуск, всего 1200 точек. Сравнение направления, номинального шага и состава здесь **описательное**. Соседние точки зависят друг от друга и от порядка программы; отношение `τ/γ̇` не создаёт второе независимое измерение. Оценку вариации между партиями, причинного эффекта состава или прогноза на новую партию этот набор не поддерживает. Для таких выводов нужен новый опыт с независимо приготовленными партиями и контролем сеансов.
