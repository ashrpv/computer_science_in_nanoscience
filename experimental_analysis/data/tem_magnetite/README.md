# Размеры частиц магнетита по ПЭМ

Реальные измерения линейного размера силуэтов частиц на просвечивающих электронных микрофотографиях. Набор предназначен для [мини-проекта курса](../../09-tem-homework.md) по организации экспериментальных данных, вложенным измерениям и интерпретации распределений. Изображений и исходной калибровки в опубликованном наборе нет: задания на пороговую сегментацию выполняются на другом учебном изображении.

## Устройство выборки

- `sample_id` обозначает **отдельно синтезированный физический образец**. Каждому из 20 включённых вариантов исходной книги соответствует один образец. Сведений о составах, режимах синтеза и их принадлежности к экспериментальным группам нет.
- `image_id` обозначает снимок **внутри образца**; номер снимка не является глобальным идентификатором и может идти с пропусками.
- Каждая строка `measurements.csv` — одно измерение частицы на конкретном снимке. Всего **20 образцов, 90 снимков, 6625 измерений**. Число измеренных частиц на снимок различается.

Следовательно, 6625 частиц и 90 снимков не образуют 6625 или 90 независимых повторов синтеза. При оценке различий между синтезами независимая единица — образец. Поскольку групповые метки и режимы не представлены, набор позволяет описывать вариацию между этими образцами, но не приписывать её определённому фактору или технологии.

## Измеряемая величина

`size_nm` — линейный размер **двумерного силуэта** в нанометрах. Для частиц округлой формы использован диаметр описанной окружности силуэта; для кубических частиц — сторона квадрата силуэта. Эти два правила не дают один и тот же геометрический признак. Форма каждой отдельной частицы в исходной таблице не размечена. Частицы крупнее примерно 25 нм чаще бывают кубическими, но это наблюдение **не является правилом классификации**: нельзя присваивать форму или пересчитывать величину по одному порогу размера.

Распределения и сводные значения ниже относятся к записанному *линейному размеру силуэта*. Без индивидуальной разметки формы их нельзя подписывать как распределение одного определённого диаметра. Метод выбора полей зрения, способ калибровки, правила исключения соприкасающихся частиц и первичные микрофотографии в этой публикации не документированы. Эти источники неопределённости нельзя оценить из одной таблицы размеров.

## Файлы и поля

- [`measurements.csv`](measurements.csv) — включённые измерения в длинной форме, UTF-8; десятичный разделитель в `size_nm` — точка.
- [`source_manifest.csv`](source_manifest.csv) — исходные номера вариантов, числа подписанных снимков и измерений, решение о включении и его основание.
- [`verify.py`](verify.py) — стандартная библиотека Python; проверка схемы, ключей и контрольных количеств опубликованных CSV.

| Колонка `measurements.csv` | Смысл |
| --- | --- |
| `sample_id` | `V01`…`V22`, номер физического образца сохраняет номер варианта исходной книги; `V14` и `V16` отсутствуют в измерениях |
| `image_id` | Заголовок «Снимок N» из исходной книги; уникален только вместе с `sample_id` |
| `particle_no` | Последовательный номер записанного значения в столбце снимка; создан при подготовке, не является исходным ID частицы |
| `size_nm` | Записанный линейный размер силуэта, нм |
| `source_cell` | Лист и адрес ячейки в исходной книге `Варианты_Задание_1.xlsx`; ссылка для сверки с первоисточником, сама книга в репозитории не опубликована |
| `import_note` | `decimal_comma` только у восьми исходных текстовых значений с запятой; у остальных пусто |

Ключ записи — `(sample_id, image_id, particle_no)`; `source_cell` также должен быть уникальным. Пустая `import_note` не означает, что была проведена проверка контура частицы на исходном снимке.

## Очистка и ограничения происхождения

В учебной книге было 22 варианта. Числовые значения **варианта 14** для шести подписанных снимков в точности повторяли 422 значения варианта 1, но были распределены по снимкам иначе. Дополнительные 213 чисел варианта 14 находились в трёх столбцах без заголовков снимков. Значения **варианта 16** точно повторяли 238 значений варианта 6, также с другой разбивкой по снимкам. Дублирование могло появиться при составлении учебных вариантов; оно не позволяет считать повторные числовые записи новыми измерениями. В опубликованной таблице оставлены `V01` и `V06`, варианты `V14` и `V16` исключены **полностью**, без попытки восстановить происхождение неподписанных столбцов.

В варианте 13 восемь значений были строками вида `12,60`. Они преобразованы в число `12.60` и отмечены `import_note=decimal_comma`; значения не отброшены. Остальные исходные числовые записи перенесены без удаления крупных или мелких значений. `source_manifest.csv` сохраняет исключённые идентификаторы и их контрольные количества. Номера оставшихся образцов не переименованы.

Проверка набора из корня репозитория:

```bash
python experimental_analysis/data/tem_magnetite/verify.py
```

Для анализа подготовьте таблицы по уровням `sample_id → image_id → particle_no`. Отдельно укажите, усредняете ли вы все зарегистрированные частицы или сначала находите характеристику каждого снимка и затем каждого образца: при разном числе частиц эти способы отвечают на разные вопросы. Например, для `V12` среднее по всем 489 частицам составляет около 36,06 нм, а среднее трёх средних по снимкам — около 39,83 нм. Ни одна из этих оценок сама по себе не исправляет возможное смещение выбора полей зрения.
