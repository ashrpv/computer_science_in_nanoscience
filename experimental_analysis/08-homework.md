# Домашнее задание. Спектры и экспериментальные кривые

Практика к [лекции 8](08-spectra_and_curves.md). Выполните задачи 1–6 на **искусственных** данных, созданных следующим кодом, или на документированных собственных измерениях. Не выдавайте искусственную кривую за приборную. Для собственного набора сохраняйте исходный файл и параметры обработки отдельно.

```python
import numpy as np

rng = np.random.default_rng(731)
wl_nm = np.arange(480., 681., 1.)
baseline = 0.06 + 0.0003 * (wl_nm - 480)
peak_1 = 1.2 * np.exp(-0.5 * ((wl_nm - 530) / 9)**2)
peak_2 = 0.6 * np.exp(-0.5 * ((wl_nm - 575) / 13)**2)
signal = baseline + peak_1 + peak_2 + rng.normal(0, 0.015, wl_nm.size)
blank = baseline + rng.normal(0, 0.005, wl_nm.size)
```

Условный образец — перовскитные квантовые точки в полимерной матрице; интенсивность дана в относительных единицах. Два пика добавлены для учебной проверки метода, но на реальных данных число компонент нельзя определять только по тому, как был написан генератор.
