## 1. Что контролирует карта (слайды 3–16)

Спецификация продукта и контрольные границы отвечают на разные вопросы. Спецификация задаёт допустимое качество по утверждённой процедуре измерения. Контрольные границы описывают обычный разброс процесса в стабильном базовом периоде. Партия может быть в спецификации и одновременно давать сигнал об изменении процесса. И наоборот, устойчивый процесс способен стабильно производить продукт вне спецификации. Поэтому нельзя проводить линии карты прямо по границам допуска.

Фаза настройки требует стабильной базы: фиксированная версия рецептуры, сопоставимые партии и приборная процедура, расследованные особые причины. Формула «среднее ± 3 стандартных отклонения» показана как простая учебная иллюстрация для партии. Для реального мониторинга следует выбрать карту с учётом подгрупп, корреляции, распределения, числа партий, правил сигнализации и частоты ложных тревог. Пять базовых партий из первой презентации для надёжной настройки недостаточны.

EWMA сглаживает наблюдения: z_t = λx_t + (1−λ)z_(t−1). Она может сделать постепенные изменения заметнее, но границы для EWMA рассчитываются отдельно. Сравнивать сглаженную кривую с границами для исходных индивидуальных точек нельзя.

Новый сигнал сначала проверяют: контрольный стандарт, независимая проба, журнал калибровки, сырьё, смена режима, пробоотбор. Пропуск датчика — событие, а не значение ноль. Удаление неудобных точек только потому, что они выходят за пределы, скрывает возможную особую причину.

## 2. Код для учебного сигнала

20 условных партий образуют базу, следующие десять содержат плавное изменение. Код показывает сигнал и EWMA без собственных контрольных границ. Результат не даёт окончательной калибровки карты для производства.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(2026)
baseline = rng.normal(116, 1.2, 20)
later = rng.normal(116 + np.linspace(0, 6, 10), 1.2)
x = np.r_[baseline, later]
mu0, sd0 = baseline.mean(), baseline.std(ddof=1)
lcl, ucl = mu0 - 3 * sd0, mu0 + 3 * sd0
signals = np.flatnonzero((x < lcl) | (x > ucl)) + 1
print('Учебные сигналы (номер партии):', signals)

lam = 0.25
z = np.empty_like(x)
prev = mu0
for i, value in enumerate(x):
    prev = lam * value + (1 - lam) * prev
    z[i] = prev

fig, ax = plt.subplots(figsize=(9, 4), layout='constrained')
ax.plot(np.arange(1, len(x) + 1), x, 'o-', label='Размер, нм')
ax.axhline(mu0, color='gray', label='Базовая средняя')
ax.axhline(ucl, color='tomato', linestyle='--', label='Иллюстративная 3σ граница')
ax.axhline(lcl, color='tomato', linestyle='--')
ax.plot(np.arange(1, len(x) + 1), z, label='EWMA (без собственных границ)')
ax.axvline(20.5, color='black', linestyle=':', label='Конец базы')
ax.set(xlabel='Номер партии', ylabel='Средний размер, нм')
ax.legend(ncol=2)
plt.show()
```

Отдельно проверьте: что произойдёт, если одна из последних партий была измерена после замены датчика? Изменится ли решение после анализа контрольного стандарта?

## 3. Цифровой двойник с физическим состоянием (слайды 17–24)

Минимальная учебная постановка содержит физическую систему, баланс для состояния C(t), модель наблюдения датчика y(t)=h(C(t))+ε(t), повторное обновление оценки по показаниям и проверку прогноза по новым партиям. Такая постановка не утверждает, что усреднённая концентрация объясняет размер всех частиц: для распределения размеров понадобилась бы иная модель, причём её следует проверить на данных.

Для идеально перемешанного объёма можно записать dC/dt = (F/V)(C_in−C)−kC. Здесь F/V и k имеют размерность обратного времени. Реальный синтез может включать неоднородное смешение и гораздо более сложную кинетику; уравнение служит прототипом для связи состояния и датчика. В коде параметры выбраны условно, численный шаг мал относительно характерного времени модели. Проверка точности численного решения потребовала бы уменьшить шаг или сравнить с аналитическим решением.

```python
dt = 0.2  # мин
time = np.arange(0, 20 + dt / 2, dt)
c = np.empty_like(time)
c[0] = 0.2
flow_over_volume, k, c_in = 0.25, 0.08, 1.4  # 1/мин, 1/мин, усл. ед.
for i in range(1, len(time)):
    dc = flow_over_volume * (c_in - c[i-1]) - k * c[i-1]
    c[i] = c[i-1] + dt * dc
observed = c[::10] + rng.normal(0, 0.025, len(c[::10]))
residual = observed - c[::10]
print('MAE на условных наблюдениях:', np.mean(np.abs(residual)))
assert np.all(c >= 0)
```

Число MAE здесь вычислено на тех же искусственных условиях и **не является независимой валидацией**. Для пилота откладывают более поздние партии; фиксируют версию модели, калибровочные интервалы и момент доступности данных. Неопределённость прогноза включает шум прибора, параметры, начальное состояние и разброс сырья. Если данные находятся вне проверенного диапазона, решение требует нового опыта.

## 4. Контроль качества и новый эксперимент (слайды 25–30)

Цикл строится последовательно: оценка состояния по датчикам, прогноз качества и неопределённости, проверка технических ограничений, выбор опыта, лабораторное QC новой партии, разбор результата и обновление модели. Предложенное изменение процесса не должно обходить ограничение оборудования или безопасность.

Один из учебных критериев: ожидаемое улучшение плюс β, умноженное на неопределённость. Он подчёркивает компромисс между использованием текущего лучшего режима и сбором информации. Число β не имеет универсального значения; оно зависит от цены опыта, цели и допустимого риска. Нельзя гарантировать улучшение только по большому баллу. Более строгие методы выбора используют ограничения и вероятность результата явно.

```python
candidates = pd.DataFrame({
    'regime': ['A', 'B', 'C'],
    'expected_improvement': [3.0, 4.2, 5.1],
    'uncertainty': [1.0, 2.0, 2.5],
    'equipment_ok': [True, True, False],
})
beta = 0.4  # учебная настройка ценности информации
feasible = candidates.loc[candidates.equipment_ok].copy()
feasible['score'] = (feasible.expected_improvement
                     + beta * feasible.uncertainty)
print(feasible.sort_values('score', ascending=False))
```

Кандидат C исключается до ранжирования, хотя его прогноз мог бы быть привлекательным. После опыта нужно сохранить и отрицательный результат: он тоже ограничивает модель.

## 5. Практика и критерии (слайды 31–36)

Практический блок модуля (3 часа) объединяет обе части: построить данные партий из первого конспекта; выделить базу и исследовать сигнал, не смешивая контрольные границы со спецификацией; написать простую модель состояния и наблюдения; предложить три допустимых режима и записать правило выбора до опыта. Сдача: воспроизводимый notebook или скрипт, два рисунка, таблица кандидатов и абзац о неопределённости. Самостоятельно (5 часов для всего модуля) студент переносит схему на свой исследовательский процесс либо на близкий учебный пример.

Проверяют, что (1) независимая единица — партия; (2) у признаков нет утечки информации из будущего; (3) сигнал ведёт к проверке причины, а не к автоматическому выводу о браке; (4) прогноз проверяется на новых партиях; (5) все режимы лежат в допустимой области. Подробное программирование PLC, SCADA и MES в модуль не входит.
