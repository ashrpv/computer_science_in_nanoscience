Цель: перейти от лабораторной рецептуры к проверяемому описанию пилотного процесса. Сквозной пример — условный синтез дисперсии SiO₂ гидролизом прекурсора. Значения объёма, температуры, pH и размера вымышлены для учебных расчётов; режимом производства они не являются.

## 1. Что переносится, а что меняется при масштабе (слайды 3–8)

Рецептура фиксирует компоненты и их количества, но результат определяется также тем, как быстро и где они смешиваются, как подводится и отводится тепло, каким образом вводится реагент. При геометрическом подобии объём пропорционален кубу линейного размера, а поверхность — квадрату. Поэтому отношение поверхности к объёму уменьшается при увеличении аппарата. Из этого нельзя непосредственно вычислить профиль температуры: нужны геометрия реального реактора, скорость тепловыделения и способ охлаждения.

Если гидролиз или конденсация идут в масштабе времени, близком ко времени смешения, локальная концентрация и pH способны различаться. Отношение времени смешения к характерному времени реакции помогает сформулировать гипотезу для пилота. Оно само по себе не устанавливает сходства двух аппаратов. Условия дозирования, точка ввода и отбор проб должны входить в протокол.

**Вопрос для аудитории.** Объёмы 2 и 20 л, состав один и тот же, а размер вырос. Какие измерения отличат изменение температуры от изменения смешения? Составьте список до просмотра результата QC.

## 2. Уровни наблюдения и качество (слайды 9–17)

Независимая партия — отдельный запуск процесса. Проба — материал, отобранный из партии. Два повторных измерения одной пробы характеризуют прежде всего аналитический этап, а не межпартийную изменчивость. В учебном примере выход — гидродинамический размер по динамическому рассеянию света (DLS). Разбавление, подготовка дисперсии, время после отбора и версия метода влияют на его значение. Не следует трактовать его как неизменный геометрический диаметр каждой частицы.

Минимальный паспорт данных хранит идентификаторы batch_id, sample_id и measurement_id; сырьевую партию, аппарат и версию рецептуры; датчики с единицами, временем, калибровкой и событиями; протокол QC и решение о партии. Изменения датчика и ручные вмешательства сохраняются как события. Датчик не переопределяет исходную историю без протокола пересчёта.

Датчики и лаборатория работают с разной частотой. Для признаков партии сначала выбирают окна относительно события, например подачи реагента. Затем вычисляют максимум температуры, время возврата в заданный диапазон и pH при отборе. Данные после момента решения нельзя применять для ретроспективно идеального «раннего» прогноза.

## 3. Связь таблиц и вариант ошибки (слайды 18–22)

Соединение каждого показания датчика со строкой QC сразу размножит итоговую метку десятки раз. Сначала агрегируйте временной ряд по партии и только затем присоединяйте лабораторный результат. Проверка validate='one_to_one' в pandas явно выдаст ошибку, если ключ перестал быть уникальным. Сохраняйте файл первичных показаний отдельно от производной таблицы признаков.

Корреляция охлаждения с плохим качеством может возникнуть потому, что оператор усиливает охлаждение после обнаружения перегрева. В журнале нужны время действия и причина. Вопрос о причинном влиянии требует плана опыта или более сильного дизайна наблюдения.

## 4. Воспроизводимый учебный пример (слайды 23–28)

Код создаёт 12 независимых условных партий, по две пробы и семь отсчётов датчиков на партию. После шестой партии одновременно меняются масштаб и версия режима: этот набор **не позволяет приписать различие размеров одному из них**. Это специально оставленная неоднозначность для обсуждения плана проверки.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(2026)
ids = [f'B{i:02d}' for i in range(1, 13)]
batches = pd.DataFrame({
    'batch_id': ids,
    'scale_l': [2] * 6 + [20] * 6,
    'recipe_version': ['R1'] * 6 + ['R2'] * 6,
    'raw_lot': ['L1', 'L2'] * 6,
})

sensor_rows = []
for j, bid in enumerate(ids):
    for minute in range(0, 61, 10):
        sensor_rows.append({
            'batch_id': bid, 'minute': minute,
            'temp_c': 25 + 0.04 * minute + (j >= 6) * 0.5 + rng.normal(0, 0.12),
            'ph': 8.2 - 0.006 * minute - (j >= 6) * 0.08 + rng.normal(0, 0.025),
        })
sensor = pd.DataFrame(sensor_rows)

samples = pd.DataFrame([
    {'sample_id': f'{bid}-S{k}', 'batch_id': bid, 'draw_minute': 60}
    for bid in ids for k in (1, 2)
])
qc = samples[['sample_id']].assign(
    size_nm=115 + samples['batch_id'].str[1:].astype(int).ge(7) * 8
    + rng.normal(0, 1.5, len(samples))
)

features = sensor.groupby('batch_id', as_index=False).agg(
    temp_max_c=('temp_c', 'max'),
    ph_end=('ph', 'last'),
)
sample_qc = samples.merge(qc, on='sample_id', validate='one_to_one')
batch_qc = sample_qc.groupby('batch_id', as_index=False).agg(
    size_mean_nm=('size_nm', 'mean'),
    size_range_nm=('size_nm', lambda s: s.max() - s.min()),
)
analysis = batches.merge(features, on='batch_id', validate='one_to_one').merge(
    batch_qc, on='batch_id', validate='one_to_one'
)
assert len(analysis) == len(ids) and analysis.batch_id.is_unique
print(analysis.round(2).to_string(index=False))
fig, ax = plt.subplots(figsize=(8, 4), layout='constrained')
ax.plot(range(1, 13), analysis.size_mean_nm, 'o-')
ax.axvline(6.5, color='gray', linestyle='--', label='Смена режима/масштаба')
ax.set(xlabel='Номер партии', ylabel='Средний размер, нм')
ax.legend()
plt.show()
```

Временной график показывает различие партий, а не причинный эффект. Для реальных данных добавьте интервалы калибровки, сырьевые партии, раздельные повторы проб и независимое подтверждение каждой гипотезы. При проверке предиктивной модели разделяйте данные по batch_id и по времени, если задача — прогноз для будущих партий.

## 5. Практика и самостоятельная работа (слайды 29–36)

На практике (3 часа) студенты: (1) строят четыре таблицы партии/датчики/пробы/QC, проверяют ключи и единицы; (2) выводят одну строку признаков на партию и рисунок с событиями; (3) формулируют две конкурирующие причины различия 2 и 20 л, предлагают пилотный опыт и критерий решения. Результат сдаётся как исполняемый notebook или скрипт, таблица признаков, график и короткий вывод. Синтетические данные выше позволяют выполнить работу без доступа к сырому производственному экспорту.

В самостоятельной работе по теме исследования обучающийся определяет параметр качества, связи партии, пробы и измерения, два физических фактора масштабирования и минимальный набор метаданных. При отсутствии собственных данных допускается аналогичный учебный процесс. Наблюдения и предположения в выводе помечают отдельно.

## Критерии результата

- Каждый признак связан с физическим смыслом, единицей и моментом доступности.
- Каждая строка аналитической таблицы относится к одной независимой партии.
- Сравнение режимов не выдаётся за чистый эффект масштаба при одновременном изменении рецептуры.
- График и таблица строятся повторно из первичных синтетических данных.
