# Задание: статистический анализ размеров наночастиц магнетита по данным ПЭМ

## Формат сдачи
Результат выполнения работы — **Jupyter Notebook** (`.ipynb`), содержащий:
- текстовые ячейки (Markdown) с пояснениями, обоснованиями и интерпретацией;
- ячейки с кодом на **Python** (рекомендуемые библиотеки: `numpy`, `pandas`, `scipy`, `matplotlib`, `seaborn`, `statsmodels`);
- выводы по каждому пункту задания.

---

## 1. Постановка задачи

Студент Х поставил **22 эксперимента** по получению наночастиц магнетита. Полученные образцы были исследованы методом **просвечивающей электронной микроскопии (ПЭМ)**. Для каждого образца было отобрано **от 3 до 10 снимков**.

Согласно результатам ПЭМ, частицы имели форму, близкую к **октаэдрической**. В качестве размера частицы использовалась **длина грани октаэдра**.

Данные о размерах частиц (по образцам и снимкам) представлены во вложенном файле.

---

## 2. Что нужно сделать

### 2.1. Анализ сходства/различия размеров и ширины распределения

Проанализируйте **сходство/различие**:
- **среднего размера** частиц;
- **ширины распределения** (дисперсии / СКО)

для **различных снимков одного и того же образца**.

При выполнении анализа:
- **явно укажите использованные допущения** (например: нормальность, независимость наблюдений, однородность дисперсий);
- **опишите способы**, которыми вы проверяли и/или улучшали соответствие данных этим допущениям (преобразования, удаление выбросов, робастные методы и т.п.).

### 2.2. Статистические критерии

Для сравнения можно использовать **F-тест** и/или **t-тест** (в том числе Уэлча).  
Допускается применение **иных статистических тестов** — при условии, что их использование **обосновано** (целесообразность, устойчивость к нарушению допущений, соответствие природе данных).

### 2.3. Проверка допущений

Для оценки соответствия данным выбранных допущений используйте:
- **оценки асимметрии и эксцесса**;
- **график нормальной вероятности (Q–Q plot)**;
- **формальные тесты нормальности** (например, **Шапиро–Уилка**, Андерсона–Дарлинга, Колмогорова–Смирнова с поправкой Лиллиефорса).

### 2.4. Преобразование данных

В ряде вариантов может потребоваться **преобразование данных** (логарифмическое, степенное, Бокса–Кокса и т.п.).  
Необходимость применения преобразования, его тип **или отсутствие такой необходимости** должны быть **разумно обоснованы** (например, с помощью анализа асимметрии, Q–Q plot, теста Бокса–Кокса).

### 2.5. Определение необходимого числа измерений

Определите **количество измерений**, обеспечивающее точность определения среднего размера **0,1 нм**.

- Доверительную вероятность выберите **самостоятельно**.
- Выбор доверительной вероятности **обоснуйте** (например, исходя из требований к точности, типичных стандартов в материаловедении, компромисса между стоимостью эксперимента и надёжностью оценки).

### 2.6. Рекомендации

Сформулируйте **рекомендации**:
- для **человека, проводившего съёмку** (оператора ПЭМ);
- для **студента Х** (исследователя, обрабатывающего данные).

Рекомендации должны опираться на полученные результаты и касаться как методики измерений, так и статистической обработки данных.
Не следует давать слишком общие рекомендации (`делать хорошо, а плохо не делать`), также не следует предполагать недобросовестность экспериментатора, оператора ПЭМ.

## 3. Требования к оформлению Notebook

1. **Структура**: каждый пункт задания — отдельный раздел (заголовок Markdown).
2. **Код**: читаемый, с комментариями; по возможности — функции для повторяющихся операций.
3. **Выводы**: после каждого раздела — краткая интерпретация результатов (не только вывод кода, но и содержательный комментарий).
4. **Визуализация**: гистограммы, boxplot/violinplot, Q–Q plot, при необходимости - графики зависимости дисперсии от среднего.
5. **Обоснования**: все допущения, тесты и преобразования должны быть явно обоснованы в текстовых ячейках.
6. **Итог**: в конце - обобщающий вывод и рекомендации (п. 2.6).

**Анализ должен быть полным, но не черезмерным (без дублирования одинаковых проверки разными тестами и т.д.)**
