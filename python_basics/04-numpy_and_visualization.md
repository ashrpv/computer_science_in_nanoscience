## 1. Массив, форма и тип

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

A = np.array([[1, 2, 3], [4, 5, 6]], dtype=float)
print(A.shape, A.ndim, A.size, A.dtype)
# (2, 3), 2, 6, float64
```

`ndarray` хранит элементы с единым `dtype`. `shape` задаёт размеры осей, `ndim` — число осей, `size` — число элементов. Запись `1.9` в целочисленный массив отбросит дробную часть. Для дробных измерений используйте вещественный тип; `a.astype(float)` создаёт преобразованный массив.

Для `A` ось 0 перечисляет две строки, ось 1 — три столбца. Это описание памяти, а не физический смысл: смысл записывают явно, например «строки — образцы, столбцы — технические измерения». Превращая список в массив, сразу проверьте `shape` и `dtype`. `np.array([1, 2.5])` выбирает общий вещественный тип; неоднородный список строк и чисел может преобразовать всё к строкам. Поэтому преобразование приборной таблицы в однородные числа должно быть явным.

```python
raw = ["41.2", "42.0", "40.8"]  # учебные значения диаметров, нм
diameter_nm = np.asarray(raw, dtype=float)
assert diameter_nm.shape == (3,)
assert np.issubdtype(diameter_nm.dtype, np.floating)
print(diameter_nm.mean())  # 41.333... нм, среднее трёх отсчётов
```

Массив не хранит единицу автоматически: переменная `diameter_nm` и подпись оси должны согласовываться с метаданными исходного файла. Разные единицы в одном столбце сначала приводят к одной, проверяя преобразование на контрольном значении. Усреднение трёх отсчётов одного образца не превращает их в три независимых синтеза.

| Задача | Выражение | Особенность |
|---|---|---|
| Последовательность с шагом | `np.arange(1, 9, 2)` | Правая граница исключена |
| Сетка из заданного числа точек | `np.linspace(0, 1, 6)` | По умолчанию включает обе границы |
| Массив нулей | `np.zeros((2, 3))` | Форма передаётся кортежем |
| Единицы той же формы | `np.ones_like(A)` | Наследует и тип, если его не задать |
| Единичная матрица | `np.eye(3)` | Единицы на диагонали |

Для вещественной сетки с известным числом точек обычно удобнее `linspace`: накопление ошибки шага у `arange` может повлиять на границу.

**Быстрая проверка:** чем `(3,)` отличается от `(3, 1)`? Каков тип `np.array(["41.2", "42.0"])` без `dtype=float`, и почему результат `mean()` в этом случае получить нельзя?

## 2. Индексы, маски, представления и копии

```python
a = np.arange(10)
selected = a[(a >= 3) & (a < 7)]
print(selected)  # [3 4 5 6]
print(A[:, 0])   # [1. 4.]
print(A[1, 1])   # 5.0

b = a[::2]      # представление: память общая
b[0] = 99
assert a[0] == 99
c = a[::2].copy()
c[0] = -1
assert a[0] == 99
```

Обычный срез обычно разделяет память с исходным массивом. Выбор по маске или массиву индексов возвращает копию. При этом присваивание `a[mask] = value` меняет исходный `a`. Условия объединяют через `&` и `|`, каждое условие заключают в скобки; обычные `and` и `or` для поэлементного сравнения не подходят.

Если нужно обработать данные и сохранить исходное измерение для повторной проверки, создайте именованную копию, а причину исключения записывайте отдельно. В следующем **отдельном учебном примере** ноль обозначает ошибку выгрузки; значение 450 нм требует проверки снимка и не удаляется автоматически:

```python
raw_nm = np.array([84., 91., 0., 450., 87.])
valid_format = np.isfinite(raw_nm) & (raw_nm > 0)
candidate_nm = raw_nm[valid_format]  # выбор по маске создаёт отдельный массив
assert np.array_equal(candidate_nm, [84., 91., 450., 87.])
print("Неположительных или нечисловых:", (~valid_format).sum())
print("Требуют проверки по первичному изображению:", (candidate_nm > 200).sum())
```

Здесь `200` нм — лишь учебный порог для проверки, а не универсальный критерий выброса. Не называйте `candidate_nm` «очищенными истинными размерами»: пригодность 450 нм решают по первичному изображению, масштабу, сегментации и протоколу. Выражение `np.isfinite` не делает решение за исследователя, но отделяет `NaN` и бесконечности от чисел.

## 3. Вычисления, форма и оси

`+`, `-`, `*`, `/`, `**` выполняют поэлементные операции; `@` задаёт матричное умножение. `np.sin` принимает радианы, `np.log` вычисляет натуральный логарифм.

```python
X = np.arange(6, dtype=float).reshape(2, 3)
print(X + np.array([10, 20, 30]))
print(X + np.array([10, 20])[:, None])
print(X.mean(axis=0))  # среднее по строкам для каждого столбца
print(X.mean(axis=1))  # среднее по столбцам для каждой строки
print(X.std(ddof=1))   # делитель N - 1
```

Broadcasting сравнивает размеры справа: они должны совпадать либо один из них должен равняться 1. `[:, None]` превращает форму `(2,)` в `(2, 1)`.

Первая сумма выше сопоставляет вектор формы `(3,)` с **тремя столбцами** каждой строки `X`: `(2, 3) + (3,) → (2, 3)`. Вторая сопоставляет вектор формы `(2, 1)` с **двумя строками**: `(2, 3) + (2, 1) → (2, 3)`. Математически возможная операция ещё не гарантирует верный смысл осей. Назовите физическое значение каждой оси до применения broadcasting.

В учебной калибровке ниже строка — концентрация, столбец — технический повтор. Темновой сигнал относится к соответствующему столбцу; вычитание работает за счёт формы `(2,)`:

```python
signals = np.array([[12., 13.], [51., 53.], [89., 92.]])  # мВ, форма (3, 2)
dark = np.array([10., 11.])  # мВ, по одному на повтор
corrected = signals - dark
assert corrected.shape == (3, 2)
print(corrected)           # [[ 2.  2.] [41. 42.] [79. 81.]]
print(corrected.mean(axis=1))  # [ 2.  41.5 80. ], по концентрациям
```

`axis=1` убирает столбцы технических повторов, оставляя по одному значению для каждой из трёх концентраций. `axis=0` убрал бы концентрации и дал по одному среднему на каждый повтор. Для более сложного массива запишите рядом схему осей, например `batch × concentration × repeat`, а затем проверьте форму результата после каждого агрегирования.

`reshape` сохраняет число элементов; один размер можно обозначить `-1`. `X.T` меняет местами оси двумерной матрицы, `ravel()` разворачивает её в одну ось. Если дальнейшие изменения должны быть независимыми, явно вызывайте `copy()`.

Для проверки близости чисел используйте `np.isclose` и `np.allclose`, выбирая `atol` и `rtol` по масштабу задачи. `np.isfinite` обнаруживает `NaN` и бесконечности. `np.nanmean` пропускает пропуски, но причину их появления это не объясняет.

`np.std(data, ddof=1)` делит сумму квадратов отклонений на `n - 1`; это **выборочная** оценка разброса значений на указанной оси, а не автоматически неопределённость среднего. При `n=1` она не определена. У `np.std` по умолчанию `ddof=0`. Для массива по уровням сначала следует определить, что считать независимой экспериментальной единицей: повторные измерения той же пробы характеризуют повторяемость измерения, разные синтезы — межпартийную вариацию.

```python
diameter_by_batch_nm = np.array([[72., 74., 73.],
                                 [81., 79., 80.],
                                 [69., 71., 70.]])
batch_mean_nm = diameter_by_batch_nm.mean(axis=1)
between_batch_sd_nm = batch_mean_nm.std(ddof=1)
assert np.array_equal(batch_mean_nm, [73., 80., 70.])
print(batch_mean_nm, between_batch_sd_nm)
```

В этом учебном примере **при условии**, что строки относятся к независимо приготовленным партиям, `n=3` партии, а не `n=9` отсчётов. Этот `between_batch_sd_nm` описывает наблюдаемый разброс средних партий; неопределённость, построение интервала и сравнительный вывод требуют отдельной постановки.

Для более подробного разбора разницы между SD, SE, доверительным интервалом и независимой единицей см. [справочник по статистике](../reference/basic_statistics.md). Группировку и сравнение образцов в Python показывает [сквозной пример](../reference/statistics_with_python.md).

## 4. Учебные измерения, CSV и линейная модель

Генератор `default_rng` хранит состояние. Фиксированный seed воспроизводит пример в той же среде; повторный вызов генератора продолжает последовательность.

```python
from numpy.polynomial import Polynomial

rng = np.random.default_rng(42)
x = np.linspace(0, 10, 21)                  # концентрация, мг/л
sigma = np.full_like(x, 0.6)                # СКО шума, мВ
y = 1.5 + 0.8 * x + rng.normal(0, sigma)    # отклик, мВ

np.savetxt("measurements.csv", np.column_stack([x, y, sigma]),
           delimiter=",", header="x,y,sigma", comments="")
x, y, sigma = np.loadtxt("measurements.csv", delimiter=",", skiprows=1).T

model = Polynomial.fit(x, y, deg=1)
b0, b1 = model.convert().coef
residual = y - model(x)
x_dense = np.linspace(x.min(), x.max(), 200)
print(b0, b1)  # примерно 1.356 и 0.824
```

`loadtxt` удобен для однородной числовой таблицы. Идентификаторы, статусы и неоднородные столбцы удобнее обрабатывать через pandas. `convert().coef` возвращает коэффициенты в исходной шкале `x`. Здесь шум одинаков во всех точках, поэтому используются равные веса.

Проверьте первые строки созданного CSV: заголовок `x,y,sigma` сам по себе **не содержит единиц**. Для собственного опыта назовите столбцы, например `concentration_mg_l`, `signal_mv`, `signal_sd_mv`, и запишите значение `sigma` в паспорте данных. Здесь `x` задан без независимых повторов, а шум с `σ=0.6` мВ имитируется ради иллюстрации; это не доказательство пригодности модели для реального прибора. Заданный seed позволяет повторить последовательность генератора, но код, версии библиотек, исходный файл и параметры метода тоже важны для воспроизводимости.

`Polynomial.fit` возвращает полином в масштабированной внутренней координате, поэтому для отчёта о коэффициентах нужен `convert()`. Функцию `model(x_dense)` можно вычислять непосредственно: объект модели сам учитывает преобразование. Линия на сетке `x_dense` — визуализация подгонки, а не дополнительные измерения. `sigma` в текущем примере **не** используется как вес: если точность уровней различается, рассмотрите модель с обоснованными весами в теме регрессии, не подставляйте автоматически одинаковые интервалы в каждую точку.

## 5. Figure, Axes и график с остатками

`Figure` — весь рисунок, `Axes` — область построения с осями. Методы `ax` позволяют явно выбирать панель. `scatter` показывает отдельные наблюдения, `plot` соединяет точки в переданном порядке. Перед построением линии зависимости проверяйте порядок `x`; для временной траектории порядок может сам иметь физический смысл.

```python
plt.style.use("dark_background")
fig, (ax, ax_res) = plt.subplots(
    2, 1, sharex=True, figsize=(7, 6), layout="constrained"
)
ax.errorbar(x, y, yerr=sigma, fmt="o", capsize=3,
            label="Измерения ±1σ")
ax.plot(x_dense, model(x_dense), "--", label="Линейная модель")
ax.set(ylabel="Отклик, мВ")
ax.legend()
ax_res.scatter(x, residual)
ax_res.axhline(0, color="gray", ls="--")
ax_res.set(xlabel="Концентрация, мг/л", ylabel="Остаток, мВ")
fig.savefig("calibration.png", dpi=150)
fig.savefig("calibration.svg")
plt.show()
```

Здесь `yerr` описывает стандартное отклонение одного измерения. Доверительный интервал среднего и интервал прогноза требуют отдельных расчётов. Тренд, кривизна или меняющийся разброс остатков указывают на возможную проблему модели или измерений.

Обратите внимание на три разных слоя одного рисунка: точки `x, y` — исходные наблюдения; вертикальные полосы `sigma` — **заданная в учебной симуляции** оценка разброса сигнала, а не подогнанный доверительный интервал; пунктир — зависимость, вычисленная по этим же точкам. Остаток каждой точки равен `y_i - model(x_i)`, измеряется в мВ и строится против соответствующей концентрации. Хорошее визуальное совпадение на этих же точках не равно проверке прогноза на новых образцах.

Для иной экспериментальной ситуации в подписи рисунка следует точно назвать смысл интервала: разброс повторных чтений прибора, стандартную неопределённость среднего, доверительный интервал или что-то ещё. Не смешивайте на одном графике исходные и средние значения без явного обозначения. Если остатки показывают систематическую кривизну, стоит проверить диапазон измерения и допущения модели до публикации «хорошего» коэффициента подгонки.

## 6. Настройка рисунка и другие типы графиков

| Задача | Инструмент | Что проверить |
|---|---|---|
| Подписи и диапазоны | `ax.set(xlabel=..., xlim=...)` | Единицы и обрезанные значения |
| Деления | `ax.set_xticks(...)` | Читаемость и физический смысл |
| Аннотация | `ax.annotate(..., xy=..., xytext=...)` | Не перекрывает ли данные |
| Логарифмическая ось | `ax.set_yscale("log")` | Все отображаемые значения положительны |
| Гистограмма | `ax.hist(values, bins=...)` | Зависимость формы от числа интервалов |
| Матрица | `ax.imshow(Z, origin="lower")` | Ориентация, `extent`, масштаб пикселя |
| Дополнительная величина цветом | `ax.scatter(..., c=values)` | Цветовая шкала и её границы |
| Несколько панелей | `plt.subplots(2, 2)` | Индексация `axs[row, col]` |

```python
fig, axs = plt.subplots(1, 2, figsize=(9, 3), layout="constrained")
m = max(float(np.max(np.abs(residual))), np.finfo(float).eps)
points = axs[0].scatter(x, y, c=residual, cmap="coolwarm", vmin=-m, vmax=m)
fig.colorbar(points, ax=axs[0], label="Остаток, мВ")
axs[0].set(xlabel="Концентрация, мг/л", ylabel="Отклик, мВ")
axs[1].hist(residual, bins=6)
axs[1].set(xlabel="Остаток, мВ", ylabel="Число наблюдений")
plt.show()
```

Цветовая шкала должна иметь подпись. `density=True` у гистограммы задаёт плотность: единице равна площадь, а не сумма высот столбцов.

Общие настройки задаются через `plt.rcParams`; цвет стоит дополнять маркером или стилем линии. `figsize` измеряется в дюймах: рисунок 6 × 4 дюйма при 150 dpi даёт 900 × 600 пикселей, если сохранение не меняет границы. `bbox_inches="tight"` может изменить размер. SVG/PDF сохраняют векторные элементы; встроенные растровые изображения остаются растром. Сохраняйте рисунок до `plt.show()`.

### Выбор типа графика как научное решение

- Для изменения сигнала с длиной волны или временем линия уместна, если соседние точки действительно задают последовательность по физической координате. Всегда отсортируйте координату перед соединением разрозненных пар, если порядок выгрузки не отражает траекторию.
- Для сравнения размеров отдельных частиц пригодны точки или распределение. Гистограмма зависит от числа и границ интервалов; по одному снимку нельзя оценивать вариацию между независимыми синтезами.
- `imshow` показывает регулярную матрицу, но без физического масштаба координаты остаются пикселями. Для измерений на изображении масштаб подтверждают по метаданным, а не по визуальной ширине на экране.
- Логарифмическая шкала помогает сравнить положительные величины на разных порядках; нули и отрицательные значения нужно явно обработать и описать, а не дать библиотеке молча скрыть их.

Следующий короткий пример демонстрирует координаты изображения. `pixel_nm = 10` — **учебное значение**, для настоящего снимка требуется независимая калибровка:

```python
intensity = np.array([[0.1, 0.4, 0.1],
                      [0.3, 1.0, 0.3],
                      [0.1, 0.5, 0.2]])
pixel_nm = 10.0
n_rows, n_cols = intensity.shape
fig, ax = plt.subplots(figsize=(4, 3), layout="constrained")
im = ax.imshow(intensity, origin="lower", cmap="viridis",
               extent=(0, n_cols * pixel_nm, 0, n_rows * pixel_nm))
ax.set(xlabel="x, нм (учебная калибровка)",
       ylabel="y, нм (учебная калибровка)")
fig.colorbar(im, ax=ax, label="Условная интенсивность")
plt.show()
```

`extent` задаёт внешние границы матрицы, поэтому изображение охватывает 0–30 нм по каждой оси, а центры трёх пикселей находятся около 5, 15 и 25 нм. Не принимайте цвет матрицы за «истинный цвет материала»: карта `viridis` кодирует числовую интенсивность. Для микрофотографии исходный цвет, цифровая яркость и физический цвет образца могут означать разные вещи.

## 7. Seaborn и таблица наблюдений

pandas `DataFrame` хранит именованные столбцы. В этом примере в каждой группе и в каждый момент используются **разные независимые наблюдения**.

```python
rng = np.random.default_rng(7)
df = pd.DataFrame({
    "group": np.repeat(["A", "B"], 20),
    "t": np.tile(np.repeat([0, 1, 2, 3], 5), 2),
})
df["signal"] = (10 + 0.4 * df["t"] + (df["group"] == "B").astype(float)
                + rng.normal(0, 0.5, len(df)))

fig, axs = plt.subplots(1, 2, figsize=(9, 4), layout="constrained")
sns.scatterplot(data=df, x="t", y="signal", hue="group", style="group", ax=axs[0])
sns.lineplot(data=df, x="t", y="signal", hue="group",
             estimator="mean", errorbar=("ci", 95), seed=7, ax=axs[1])
for ax in axs:
    ax.set(xlabel="Время, с", ylabel="Отклик, мВ")
plt.show()
```

`hue` задаёт цвет по группе, `style` — маркер или стиль линии, `ax` связывает Seaborn с панелью Matplotlib. `lineplot` по умолчанию агрегирует повторы при одинаковом `x`; это нужно учитывать при чтении рисунка. Для отдельных траекторий задают ID в `units`, `estimator=None` и отключают интервалы. При повторных измерениях одного объекта интервалы должны учитывать зависимость наблюдений.

Для сравнения распределений при фиксированном времени можно совместить `boxplot` и `swarmplot`: коробка даёт сводку, точки показывают наблюдения. Если все точки выводятся отдельно, `showfliers=False` скрывает только дублирующиеся маркеры выбросов коробки, а не удаляет данные.

```python
df_t3 = df.loc[df["t"] == 3].copy()
fig, ax = plt.subplots(figsize=(5, 4), layout="constrained")
sns.boxplot(data=df_t3, x="group", y="signal", showfliers=False,
            color="lightgray", ax=ax)
sns.swarmplot(data=df_t3, x="group", y="signal", color="tab:blue", ax=ax)
ax.set(xlabel="Группа", ylabel="Отклик, мВ",
       title="Учебные независимые наблюдения при t = 3 с")
plt.show()
```

На этом графике в каждом из двух условий по пять отдельных учебных наблюдений. `swarmplot` может плохо работать при очень больших наборах из-за перекрытий и вычислительной стоимости: тогда используют прозрачные точки, подвыборку только для рисунка с явной пометкой либо сводные распределения. `lineplot(errorbar=("ci", 95))` вычисляет интервал по своей процедуре агрегирования; не считайте его автоматически интервалом для будущего независимо синтезированного образца. Для связанных измерений нужны идентификаторы объектов и другая схема визуализации.

### Контрольные вопросы и короткие ответы

1. Почему `signals - dark` даёт три строки по два значения? Последние размерности обеих форм равны 2; вектор `dark` повторяется по трём строкам. Но правильность **смысла** такого вычитания зависит от того, что его два элемента действительно относятся к тем же техническим повторам.
2. Почему `a[::2][0] = 99` изменило `a`, а `candidate_nm[0] = ...` не изменит `raw_nm`? Срез обычно даёт представление с общей памятью, а выбор по маске — новый массив.
3. Что означает `batch_mean_nm.mean()`? Среднее **трёх средних партий** при указанном устройстве данных. Можно ли назвать его средним по трём независимым синтезам, решает паспорт образцов, а не форма массива.
4. Какая проверка нужна перед `np.log(y)` и логарифмической осью? Проверка положительности, конечности и физического смысла значений. Выбор основания логарифма и обработку нулей следует записать.
5. Почему линия `model(x_dense)` содержит 200 точек, но `n=21` наблюдение? Сетка плотной отрисовки не меняет размер исходной выборки и не добавляет независимых измерений.
