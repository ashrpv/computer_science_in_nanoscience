## Определение функции и область видимости

### 1. Стоп-зона фотонного кристалла

В упрощённой модели при нормальном падении света длина волны отражения `wavelength_nm = 2 * d111_nm * n_eff`, где `d111_nm` — расстояние между отражающими плоскостями (нм), а `n_eff` — безразмерный эффективный показатель преломления. **Расстояние между плоскостями не тождественно диаметру сфер.** Для идеальной плотно упакованной гранецентрированной кубической решётки можно оценить `d111_nm = (2/3)**0.5 * sphere_diameter_nm`; это отдельное геометрическое допущение.

Напишите функцию `calculate_stop_zone(d111_nm, n_eff)`, которая возвращает длину волны в нм. Сначала из условного диаметра сфер 230 нм найдите `d111_nm` по приведённой оценке, затем вызовите функцию при `n_eff = 1.45` и напечатайте результат с единицей. Это ориентир для учебного примера, не установленный спектральный максимум реального опала.

Функция должна только возвращать значение (return), но ничего не печатать сама.

**Самопроверка:** если `d111_nm` удвоить при неизменном `n_eff`, результат удвоится. **Подсказка:** расчёт геометрического расстояния можно выполнить до вызова функции.

### 2. Локальная и глобальная переменные

В учебной программе обработки токов задан `BACKGROUND_CURRENT = 0.005` мА. Записи ниже демонстрируют область видимости, а не процедуру калибровки настоящего потенциостата.

Напишите функцию `adjust_signal(measured_current)`. Внутри функции:

1. Создайте локальную переменную `noise = 0.001`.
2. Присвойте **внутри функции** `BACKGROUND_CURRENT = 0.008` без ключевого слова `global`.
3. Функция должна возвращать чистый сигнал: `measured_current - BACKGROUND_CURRENT - noise`.

Вызовите функцию для значения 0.050 мА, а затем выведите `BACKGROUND_CURRENT` в основном коде. Объясните, какое значение было прочитано при вычислении функции и почему глобальная переменная сохранилась. Попробуйте передать значение фона параметром в **отдельной улучшенной версии** функции, не изменяя глобальное состояние.

**Самопроверка:** вывод после вызова показывает прежние `0.005` мА. **Подсказка:** присваивание имени в функции делает его локальным, если не объявлен `global`.

### 6. Среднее нескольких технических измерений

Получены учебные повторные оценки гидродинамического **радиуса** одного образца (нм). Несколько отсчётов одного образца не равны независимым синтезам, а радиус не нужно выдавать за диаметр.

Напишите функцию `get_average_radius_nm(*radii_nm)`, которая принимает любое количество радиусов (позиционные аргументы) и возвращает среднее арифметическое в нм. Покажите результаты для `(71, 73, 72)` и `(80, 82)`.

Если измерений нет (`get_average_radius_nm()`), функция должна возвращать `None`, а не делить на ноль. При выводе пометьте этот результат как «нет данных». В реальной таблице наблюдений такой случай записывают как пропуск с указанной причиной, а не как нулевой радиус.

**Самопроверка:** пустой вызов возвращает `None`, одиночное измерение возвращает его значение. Нулевой радиус как измерение в этой постановке недопустим; дополнительно можно проверять, что все переданные радиусы строго положительны.

### 8. Регистрация условной фазовой системы

Для записи условного состава «лецитин — масло — вода» нужен журнал, в котором различаются перечисленные компоненты и их массовые доли. **Один вызов не даёт фазовую диаграмму и не устанавливает реальное фазовое состояние.**

Напишите функцию `register_phase_system(operator, *components, state="Жидкие кристаллы", **fractions)`. Она должна принимать:

- Имя исследователя (`operator`).
- Любое количество присутствующих веществ (`*components`).
- Текущее фазовое состояние как параметр по умолчанию (`state`).
- Массовые доли компонентов в виде именованных параметров (`**fractions`).

Функция должна возвращать **словарь** с ключами `operator`, `components`, `state`, `fractions`. Продемонстрируйте вызовы с фазовым состоянием по умолчанию и с другим заданным состоянием. Для учебного примера используйте три доли `lecithin=0.35`, `oil=0.25`, `water=0.40` (доли единицы); объясните, почему перечисление компонентов и сумма долей должны согласовываться. Проверка суммы — дополнительная задача.

**Самопроверка:** `components` содержит переданные имена, а `fractions` — словарь именованных долей; два вызова не меняют данные друг друга. **Подсказка:** кортеж `components` и словарь `fractions` можно поместить в возвращаемый словарь без преобразования в строку.

### 9. Экспресс-анализ сорбционной ёмкости

Получен массив данных по сорбции предельных углеводородов внутри пор полимерных нанокомпозитов (в граммах поглощенного вещества на грамм сорбента): `sorption_data = [4.2, 5.1, 3.8, 4.2, 6.0, 3.9, 5.1]`.

Не используя циклы (`for`, `while`), с помощью встроенных функций Python:

1. Определите максимальное и минимальное значения сорбции.
2. Рассчитайте среднюю сорбционную емкость по формуле `sum() / len()`.
3. Создайте из списка множество (`set`), чтобы узнать количество уникальных результатов измерений, и выведите его длину.

Выведите числа с единицей «г/г». Одинаковые значения не обязательно являются ошибочными дублями: здесь множество используют лишь для **подсчёта различных записанных значений**, а среднее считают по исходному списку.

**Самопроверка:** уникальных значений пять; число значений списка семь. **Подсказка:** `set()` меняет состав повторений, поэтому не подставляйте множество в расчёт среднего.
