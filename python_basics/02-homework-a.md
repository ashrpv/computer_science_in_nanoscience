## 1. Положение стоп-зоны опалового фотонного кристалла

Для идеализированного плотноупакованного опала с гранецентрированной кубической решёткой нормальное падение на плоскости (111) даёт приближение $\lambda \approx 2d_{111}n_{\mathrm{eff}}$, где **межплоскостное расстояние** $d_{111}=\sqrt{2/3}\,D$, $D$ — диаметр сфер в нм, а $n_{\mathrm{eff}}$ — эффективный показатель преломления. Не отождествляйте $d_{111}$ и $D$; порядок, ориентация и окружение образца ограничивают точность оценки.

Напишите функцию `calculate_stop_zone(D_nm, n_eff)`, которая возвращает приблизительную длину волны в нм. Вызовите её при `D_nm = 230` и `n_eff = 1.45`; выведите результат вне функции и проверьте, что он составляет примерно 544.6 нм. Для квадратного корня можно использовать `math.sqrt`.

Функция должна только возвращать значение (return), но ничего не печатать сама.

## 2. Области видимости и фоновый ток

Вызовите функцию для `0.050` и выведите значение `background_current_ma` вне функции: ожидаются соответственно `0.041` и `0.005` мА (с учётом погрешности представления `float`). Затем создайте **отдельную** функцию `correct_signal(measured_current_ma, background_current_ma, noise_ma=0.001)`, которая получает фактический фон аргументом, и проверьте вызов с `0.050` и `0.005`: ожидается `0.044` мА. ## 6. Средний размер липидных наночастиц

Для одного учебного образца липидных наночастиц есть несколько технических оценок **гидродинамического диаметра**, выраженного в нм. Это повторы измерения одного образца, а не независимые синтезы; арифметическое среднее этих учебных значений не заменяет полный анализ корреляционной функции ДРС.

Напишите функцию `get_average_particle_size(*args)`, которая принимает любое количество положительных оценок диаметра (как позиционные аргументы) и возвращает их среднее арифметическое. Покажите вызовы с тремя значениями и с одним значением.

## Дополнительная самостоятельная практика: поток калибровочных записей

Небольшое продолжение тем про чистые функции и генераторы. Даны **учебные** строки:

```python
rows = [
    {"sample_id": "S-01", "signal_mv": 5.5},
    {"sample_id": "S-02", "signal_mv": 10.5},
    {"sample_id": "S-03", "signal_mv": 0.7},
]
```

Напишите функцию `concentration_mg_l(signal_mv, *, intercept_mv, slope_mv_per_mg_l)` для расчёта $(signal - intercept)/slope$. При нулевом или отрицательном наклоне выбрасывайте `ValueError` согласно **учебному** допущению. Затем напишите генератор `calibrated_rows(rows)`, который для каждой входной записи создаёт **новый** словарь с `sample_id`, `signal_mv`, результатом расчёта при `intercept_mv=1.5`, `slope_mv_per_mg_l=0.8` и статусом `"в диапазоне"` или `"проверить диапазон"` для калибровочного интервала 0–10 мг/л включительно. Выведите `list(calibrated_rows(rows))`, проверьте результаты 5.0, 11.25 и −1.0 мг/л и убедитесь, что исходный `rows` не изменился. Отрицательный вычисленный результат пометьте, но не удаляйте: без паспорта метода он не даёт основания менять исходный сигнал.
