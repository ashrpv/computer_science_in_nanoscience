# Модуль 1: Основы Python

Первый модуль курса «Информатика в нанонауке». Здесь собраны материалы для изучения базового синтаксиса Python и его применения к задачам нанотехнологий — от работы со строками и списками до функций и генераторов коллекций.

## Файлы модуля

| Файл | Что это |
|---|---|
| [`01-memo.md`](01-memo.md) | Конспект-шпаргалка: все базовые конструкции Python с примерами |
| [`01-first_homework.md`](01-first_homework.md) | Домашнее задание: 10 задач в контексте нанонауки |

> Запускаемых `.py`-файлов в модуле пока нет — их создаёт обучающийся при выполнении заданий.

Конспект состоит из 16 разделов:

| № | Тема | Что внутри |
|---|---|---|
| 1 | Философия Python (Zen of Python) | Принципы `import this`, практические выводы |

| 3 | Числа и арифметика | Операторы, целочисленное деление, погрешность `float`, сравнения |

| 5 | Списки | Методы, операции, изменяемость |
| 6 | Словари (dict) | Ключи и значения, доступ, `.get()`, просмотры |
| 7 | Множества (set) | Уникальность элементов, операции над множествами |
| 8 | Кортежи (tuple) | Неизменяемость, упаковка и распаковка |
| 9 | Условные операторы | `if/elif/else`, тернарный оператор, truthiness |
| 10 | Циклы | `for`, `while`, `range`, `break`/`continue`, `for...else` |

## Домашнее задание ([`01-first_homework.md`](01-first_homework.md))

10 задач, сгруппированных по темам:

| Блок | Тема | Задачи |
|---|---|---|
| Блок 1 | Типы данных и базовые операции | 1. Квантовый конфигуратор · 2. Масштаб атома |
| Блок 2 | Условный оператор (if-elif-else) | 3. Сортировщик наночастиц · 4. Проверка стабильности фуллерена |
| Блок 3 | Циклы (for и while) | 5. Рост нанокристалла · 6. Спектральный анализ |
| Блок 4 | Комплексные задачи | 7. Симуляция СТМ-микроскопа · 8. Аварийная остановка сборки |
| Дополнительно | Словари и множества | 9. Паспорт наноматериала · 10. Фильтрация примесей |

> Каждая задача оформлена в формате «Контекст -> Задача» и опирается на соответствующий раздел конспекта.

## Как работать с модулем

1. Прочитайте конспект [`01-memo.md`](01-memo.md) — по одному разделу за раз, повторяя примеры в интерпретаторе.
2. Открывайте задания из [`01-first_homework.md`](01-first_homework.md) и решайте их в отдельных `.py`-файлах.
3. В непонятных местах сверяйтесь с конспектом и шпаргалкой «что где искать» (раздел 15).
4. Запускайте свои решения командой `python имя_файла.py`.

## Требования

- **Python 3.7+** (темы про `match/case` и порядок словарей опираются на более новые версии)
- Дополнительные библиотеки не требуются — только стандартная библиотека
