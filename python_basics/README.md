# Модуль 1: Python для научных данных

Первый модуль курса «Компьютерные и информационные технологии в нанонауке». Здесь собраны материалы для изучения базового синтаксиса Python и его применения к задачам нанотехнологий — от работы со строками и списками до функций, числовых массивов и визуализации. Первые две презентации объединены в конспекте `01-basics_and_types.md`, третья соответствует `02-functions.md`, четвёртая — `04-numpy_and_visualization.md`. Полный порядок задан в [оглавлении курса](../README.md).

## Как работать с модулем

1. Прочитайте конспект [`01-basics_and_types.md`](01-basics_and_types.md) — по одному разделу за раз, повторяя примеры в интерпретаторе.
2. Открывайте задания из [`01-first_homework.md`](01-first_homework.md) и решайте их в отдельных `.py`-файлах.
3. В непонятных местах сверяйтесь с конспектом и шпаргалкой «что где искать» (раздел 15).
4. Перейдите к конспекту [`02-functions.md`](02-functions.md) и закрепите материал задачами из [`02-homework-a.md`](02-homework-a.md).
5. Изучите [NumPy и визуализацию](04-numpy_and_visualization.md), последовательно выполняя примеры в отдельной сессии.
6. Запускайте свои решения командой `python имя_файла.py`.

## Требования

Для полного комплекта используйте Python 3.11 или 3.12. Первые два конспекта и домашние задания используют стандартную библиотеку; для NumPy и визуализации нужны дополнительные пакеты из [requirements.txt](../requirements.txt). Настройка окружения описана в [README курса](../README.md).
