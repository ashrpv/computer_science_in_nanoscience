## 🔬 Блок 1. Массивы и контроль измерений

### 1. Размер капель наноэмульсии (маски и статистики)

**Контекст:** При анализе микроскопических изображений персиковой эмульсии получены диаметры капель в нм: `diameter_nm = [84, 91, 88, 0, 95, 87, 450, 90]`. Ноль обозначает ошибку выгрузки; значение 450 требует проверки и не должно автоматически удаляться.

**Задача:** Создайте массив NumPy, выделите маской положительные значения, рассчитайте среднее и медиану. Затем **в качестве анализа чувствительности**, а не окончательной чистки данных, отдельно рассчитайте их для диапазона 50–200 нм и покажите разницу. Выведите количество и причины отдельно для нуля (ошибка выгрузки по условию) и для 450 нм (вне выбранного диапазона, требуется проверка): в каждом случае одна точка. Сохраните исходный массив и сформулируйте, какие сведения о снимке, масштабе и сегментации нужны, чтобы решить судьбу значения 450 нм.

### 2. Две партии липидных наночастиц (оси и независимость)

**Контекст:** Для трёх независимо приготовленных партий **одной и той же учебной рецептуры** измерены радиусы в трёх технических повторах (нм):


**Задача:** Рассчитайте среднее по измерениям каждой партии и общее среднее трёх партий с использованием `axis`. Выведите форму массива до и после усреднения. Постройте график трёх средних с точками технических повторов. Проверьте средние партий 73, 80 и 70 нм. Объясните, почему здесь `n = 3` независимые партии этой рецептуры, а не `n = 9` технических отсчётов. В этих данных нет другой рецептуры, поэтому её сравнение поставить нельзя.

### 3. Калибровка люминесценции квантовых точек (broadcasting)

**Задача:** Вычтите темновой сигнал посредством broadcasting, не используя цикл по концентрациям. Проверьте форму результата. Для каждого уровня концентрации найдите среднее и размах скорректированного сигнала. Постройте график с исходными точками и средними; укажите, что это учебная калибровка, а два отсчёта не обеспечивают оценку устойчивости разных синтезов.
