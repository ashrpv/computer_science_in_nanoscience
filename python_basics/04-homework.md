### 1. Размер капель наноэмульсии (маски и статистики)

**Контекст:** При анализе микроскопических изображений персиковой эмульсии получены диаметры капель в нм: `diameter_nm = [84, 91, 88, 0, 95, 87, 450, 90]`. Ноль обозначает ошибку выгрузки; значение 450 требует проверки и не должно автоматически удаляться.

**Задача:** Создайте массив NumPy, выделите маской положительные значения, рассчитайте среднее и медиану. Затем отдельно рассчитайте их для диапазона 50–200 нм и покажите разницу. ### 2. Три партии липидных наночастиц (оси и независимость)

**Контекст:** Для трёх независимо приготовленных партий измерены размеры в трёх технических повторах (нм):

```python

```

**Задача:** Рассчитайте среднее по измерениям каждой партии и общее среднее трёх партий с использованием `axis`. Выведите форму массива до и после усреднения. Постройте график трёх средних с точками технических повторов (ось x — ID партии, ось y — радиус, нм); точки повторов должны находиться у своей партии. Объясните, почему для характеристики вариации между партиями здесь `n = 3`, а не `n = 9` отсчётов. Все три партии приготовлены по **одной рецептуре**, поэтому этими данными нельзя сравнить разные рецептуры.

**Самопроверка:** входная форма `(3, 3)`, средних по партиям три; среднее повторов первой партии равно 73 нм. **Подсказка:** строки — партии, столбцы — технические повторы; усредняйте по оси столбцов.

### 3. Калибровка люминесценции квантовых точек (broadcasting)

**Контекст:** Для трёх концентраций квантовых точек `[0, 2, 4]` мг/л получены сигналы при двух повторах: `[[12, 13], [51, 53], [89, 92]]` условных единиц. Темновой сигнал соответствующих повторов — `[10, 11]`.

**Задача:** Вычтите темновой сигнал посредством broadcasting, не используя цикл по концентрациям. Считайте, что первый темновой отсчёт относится к **первому столбцу каждого уровня**, второй — ко второму; для реальных измерений это соответствие потребовало бы метаданных. Проверьте форму результата. Для каждого уровня концентрации найдите среднее и размах скорректированного сигнала (максимум минус минимум). Постройте график с индивидуальными **скорректированными** точками и средними; подпишите оси `Концентрация, мг/л` и `Сигнал после вычитания фона, усл. ед.`. Укажите, что это учебная калибровка, а два отсчёта не обеспечивают оценки устойчивости разных синтезов.

**Самопроверка:** результат имеет форму `(3, 2)`, в первой строке оба значения равны 2; уровень 0 мг/л не становится нулём автоматически. **Подсказка:** форма вектора темновых значений `(2,)` согласуется с последней осью матрицы `(3, 2)`.
