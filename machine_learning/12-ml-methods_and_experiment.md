# Машинное обучение: выбор метода и следующего эксперимента

Материал для лекции 12. [Лекция 11](11-ml-problem_and_validation.md) задаёт единицу наблюдения, baseline и проверку на новых группах. Здесь мы сравниваем компактные модели для небольших наборов, рассматриваем многомерные измерения и превращаем прогноз в предложение опыта. Числа и наборы ниже учебные.

## Результат занятия

Студент может выбрать метод под тип признаков и объём независимых наблюдений, сравнить Ridge, PLS, случайный лес и градиентный бустинг на одинаковых групповых складках, объяснить роль PCA и PLS, критически интерпретировать важность признаков и предложить проверяемый следующий опыт. Он может описать вычисление прогноза и обучение простой нейронной сети, формализовать задачу последовательного управления как обучение с подкреплением и объяснить, какие данные и проверки нужны для каждого подхода. Реализация нейросети и агента управления не обязательна.

## 1. Лестница моделей для малой лабораторной выборки

Сначала сравнивают лабораторное правило и `DummyRegressor`, затем линейную модель и регуляризацию, PLS для коррелированных спектральных каналов, дерево или ансамбль для нелинейностей. Это не обязательная иерархия победителей. Порядок помогает понять, за какую сложность платят данными и интерпретируемостью. Для каждой модели входы должны быть доступны в тот же момент решения, а схемы train/test — одинаковы.

| Метод | Когда рассмотреть | Что проверить |
|---|---|---|
| Ridge/Lasso | Числовые дескрипторы, примерно гладкая связь | Масштаб, коэффициенты, устойчивость к выборке |
| PLS | Много коррелированных спектральных каналов | Число компонент только через CV |
| Дерево | Пороговые взаимодействия, немного факторов | Глубину, переобучение, нестабильность |
| Random forest | Нелинейная связь, достаточно независимых партий | Перенос на новые диапазоны и партии |
| Градиентный бустинг | Нелинейные табличные зависимости | Глубину слабых деревьев, скорость обучения, остановку и число партий |

Линейная интерполяция, деревья и лес не гарантируют надёжной **экстраполяции** за диапазоны синтеза. Если цель содержит физическое ограничение, его нельзя автоматически считать соблюдённым прогнозом произвольной модели. В некоторых проектах механистическая модель предыдущей лекции — более сильный baseline, чем среднее.

## 2. Регуляризованная регрессия и интерпретация

Ridge минимизирует сумму квадратов ошибок с штрафом `α||β||²`, Lasso — с `α||β||₁`. При коррелированных дескрипторах Ridge распределяет вклад между ними, а Lasso может выбрать один из нескольких похожих столбцов; выбор не доказывает, что этот столбец является механизмом. Чтобы штраф одинаково относился к величинам в разных единицах, масштабирование включают в `Pipeline`. Значение `α` выбирают по обучающим групповым складкам; внешнюю оценку после выбора не используют для следующего подбора.

Коэффициент имеет условный смысл «при прочих равных» в параметризации модели и подготовленных признаках. Для причинного вывода нужны дизайн опыта и дополнительные предпосылки. Тесная корреляция температуры и времени синтеза затрудняет раздельную интерпретацию даже при хорошем прогнозе.

## 3. PLS для спектров

Спектр из сотен длин волн даёт матрицу `X`, где соседние каналы сильно коррелируют. PCA ищет направления большой дисперсии `X` без целевого свойства. PLS использует также `y` и строит компоненты для предсказания свойства. Поэтому PLS — supervised метод, а PCA — unsupervised. Ни «95% дисперсии PCA», ни разделение точек на двумерном графике не гарантируют хороший прогноз `y`.

Спектры нормируют, исправляют фон или выравнивают только по заранее зафиксированному протоколу либо внутри обучающих складок, если параметры оценки зависят от набора. Целевая связь, отбор длин волн и число компонент нельзя определять по полному набору до CV. Для нового прибора проверяют перенос по прибору отдельно.

```python
import numpy as np
from sklearn.cross_decomposition import PLSRegression
from sklearn.model_selection import GroupKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(12)
n_batches, channels = 30, 24
groups = np.arange(n_batches)
concentration = rng.uniform(0.1, 1.0, n_batches)
axis = np.linspace(0, 1, channels)
peak = np.exp(-0.5 * ((axis - 0.55) / 0.12) ** 2)
X = 0.8 + concentration[:, None] * peak + rng.normal(0, 0.04, (n_batches, channels))
y = 2.0 + 3.2 * concentration + rng.normal(0, 0.12, n_batches)

cv = GroupKFold(n_splits=5)
for n_components in [1, 2, 3, 4]:
    pipe = make_pipeline(StandardScaler(), PLSRegression(n_components=n_components))
    mae = -cross_val_score(pipe, X, y, cv=cv, groups=groups,
                          scoring="neg_mean_absolute_error")
    print(n_components, round(mae.mean(), 3), round(mae.std(), 3))
```

Это демонстрация выбора числа компонент **внутри разработки**. Если приведённые результаты сравнивают и потом объявляют лучшее число «проверенным качеством», получается оптимистичная оценка. Для отчёта нужен заранее отложенный тест или вложенная CV. Здесь по одной строке на партию, поэтому группирование тривиально и показывает протокол, который сохраняется при добавлении повторов.

## 4. Деревья, случайный лес и градиентный бустинг

Дерево делит пространство по порогам. Его легко читать, но глубокое дерево чувствительно к малым изменениям данных. Лес усредняет множество деревьев и может устойчивее предсказывать внутри области обучения; сам по себе он не исправляет смещение выборки. `max_depth`, `min_samples_leaf`, число признаков и другие настройки задают сложность и подбираются по групповым складкам. Сравнивайте ошибку с простыми моделями на одинаковых новых партиях.

Для задачи с очень малым `n_groups` большое число деревьев не создаёт новые эксперименты. Точно так же множество пикселей и каналов не компенсирует три независимо синтезированные партии. При технически смешанных признаках можно применять `ColumnTransformer`, но код и параметры преобразований должны оставаться в складке.

### Как устроены два ансамбля

**Случайный лес** обучает много деревьев на разных bootstrap-выборках и со случайным отбором признаков при разбиениях, затем усредняет их прогнозы для регрессии. Деревья можно строить независимо; усреднение в основном уменьшает разброс, присущий одиночному дереву. В лабораторных данных bootstrap делается по независимым единицам, а не создаёт новые физические партии. Если строк несколько на партию, предварительно агрегируйте их или строьте процедуру на уровне партий.

**Градиентный бустинг** добавляет небольшие деревья *последовательно*: $F_m(x)=F_{m-1}(x)+\eta h_m(x)$, где $\eta$ — скорость обучения. Для квадратичной функции потерь новое дерево приближает остатки $y_i-F_{m-1}(x_i)$, то есть направление уменьшения ошибки; в общем случае оно приближает **отрицательный градиент** функции потерь. Для классификации с логистической потерей это уже не простое вычитание метки из класса. Малое $\eta$ обычно требует большего числа шагов. Большая глубина дерева и длительное обучение могут подстроиться под шум и особенности партии.

### Один шаг на четырёх условных измерениях

Пусть температура синтеза $x$ и измеренное свойство $y$ имеют значения:

| $x$, °C | 80 | 85 | 95 | 100 |
|---:|---:|---:|---:|---:|
| $y$, усл. ед. | 4 | 6 | 10 | 12 |
| Константа $F_0=\overline y$ | 8 | 8 | 8 | 8 |
| Остаток $y-F_0$ | −4 | −2 | +2 | +4 |
| Неглубокое дерево $h_1$ | −3 | −3 | +3 | +3 |
| $F_1=F_0+0{,}5h_1$ | 6,5 | 6,5 | 9,5 | 9,5 |

Дерево разделило температуры по порогу 90 °C и предсказало *средний остаток* в каждой половине. При $\eta=0{,}5$ исправление сделано лишь наполовину. Следующее дерево учится на новых остатках $(-2{,}5,-0{,}5,+0{,}5,+2{,}5)$, а не независимо повторяет первую модель. **Все числа здесь вымышлены**; на четырёх наблюдениях обучение ансамбля ради практического прогноза не обосновано. Механизм объясняет и отличие от леса, и необходимость следить за переобучением.

На небольшом табличном наборе сравнивайте `RandomForestRegressor` и `HistGradientBoostingRegressor` с Ridge на **одних** удержанных группах. Для малого набора можно взять `GradientBoostingRegressor` с неглубокими деревьями. При использовании ранней остановки обычное случайное `validation_fraction` может разбить одну партию или кампанию между обучением и внутренней проверкой: настройку и остановку нужно проводить с учётом групп либо отключить встроенную раннюю остановку и выбирать число итераций во внешней групповой схеме разработки. Параметры `learning_rate`, `max_iter`/`n_estimators`, `max_leaf_nodes`/`max_depth` и `min_samples_leaf` меняют сложность. В отчёте показывают диапазон ошибок по кампаниям, а не только среднюю цифру.

```python
import numpy as np
from sklearn.dummy import DummyRegressor
from sklearn.ensemble import GradientBoostingRegressor, RandomForestRegressor
from sklearn.linear_model import Ridge
from sklearn.model_selection import GroupKFold, cross_validate
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

# Искусственные табличные данные: 12 кампаний по 4 независимые партии.
rng = np.random.default_rng(12)
campaign_id = np.repeat(np.arange(12), 4)
temp_c = rng.uniform(75, 105, 48)
fraction_pct = rng.uniform(0, 3, 48)
X_tab = np.column_stack((temp_c, fraction_pct))
y_tab = (40 + 0.05 * (temp_c - 90)**2 + 3 * fraction_pct
         + rng.normal(0, 2, 12)[campaign_id] + rng.normal(0, 1, 48))

# Демонстрация на разработке: финального удержанного теста здесь нет.
cv = GroupKFold(n_splits=4)
models = {
    "mean": DummyRegressor(),
    "ridge": make_pipeline(StandardScaler(), Ridge(alpha=10)),
    "forest": RandomForestRegressor(n_estimators=100, min_samples_leaf=3,
                                     random_state=12),
    "boosting": GradientBoostingRegressor(n_estimators=60, learning_rate=0.05,
                                          max_depth=2, min_samples_leaf=3,
                                          random_state=12),
}
for name, model in models.items():
    scores = cross_validate(model, X_tab, y_tab, cv=cv, groups=campaign_id,
                            scoring="neg_mean_absolute_error")
    print(name, -scores["test_score"])  # ошибка каждой складки из целых кампаний
```

Параметры в примере зафиксированы заранее. Если после просмотра складок их меняют, это уже **настройка**; для итоговой ошибки используют внешний тест или вложенную CV. Для категориальных входов нужен соответствующий конвейер подготовки, обучаемый внутри каждой складки.

## 5. PCA: карта вариации, не карта истины

PCA представляет стандартизованные признаки через ортогональные компоненты с максимальной дисперсией. Перед анализом выбирают признаки, единицы, масштабирование и правила обработки пропусков. Точки на графике PC1–PC2 окрашивают известной меткой **для интерпретации**, но положение меток не использовалось при построении PCA. Загрузки помогают понять, какие исходные переменные влияют на компоненты; сильно коррелированные признаки и порядок предобработки могут менять их смысл.

Если приборный дрейф создаёт больше вариации, чем химический состав, PC1 может прежде всего описывать день измерения. Рекомендуется окрашивать одну и ту же проекцию по партии, дню, прибору и целевому свойству. Для применения PCA в прогнозной модели объект `PCA` обучают внутри `Pipeline` на train каждого разбиения. `fit_transform` на всех спектрах до разбиения нарушает чистоту проверки, хотя PCA не использует `y`.

## 6. Кластеризация и проверка устойчивости

`KMeans` разбивает точки вокруг центров в выбранном масштабе и требует заранее заданное число кластеров. Метки кластеров произвольны; без внешней проверки их нельзя назвать фазами материала, механизмами или классами качества. Показатель silhouette описывает геометрию разделения для данных и метрики, но высокое значение не доказывает научную интерпретацию. Сравните разные масштабы, состав признаков, число кластеров и партии, а затем исследуйте реальные образцы из каждой группы.

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler

# Искусственные спектры: два положения пика, 15 независимых образцов каждое.
rng = np.random.default_rng(12)
axis = np.linspace(0, 1, 24)
centers = np.r_[np.full(15, 0.35), np.full(15, 0.70)]
X = np.array([np.exp(-0.5 * ((axis - c) / 0.12)**2)
              + rng.normal(0, 0.06, axis.size) for c in centers])
X_scaled = StandardScaler().fit_transform(X)  # только исследовательский анализ текущего набора
scores = PCA(n_components=2).fit_transform(X_scaled)
for k in [2, 3, 4]:
    labels = KMeans(n_clusters=k, n_init=10, random_state=12).fit_predict(X_scaled)
    print(k, round(silhouette_score(X_scaled, labels), 3))
```

Код показывает **описательную** структуру искусственных спектров. При оценке переноса кластеров на будущие образцы масштабирование и PCA обучают только на обучающей части, а вывод проверяют независимо. Даже при хорошем silhouette может оказаться, что алгоритм разделил партии по фону прибора.

## 7. Объяснение прогноза и область применимости

Перестановочная важность измеряет падение выбранной метрики после нарушения одного признака на заданном наборе. При сильной корреляции признаков её значение может быть малым для каждого столбца: модель использует соседний коррелированный столбец. Проверка должна опираться на уже обученную модель и независимые партии; многократный просмотр теста для изменения признаков нарушает его роль. Partial dependence усредняет прогноз при замене признака, иногда создавая несуществующие комбинации условий. Эти методы описывают поведение модели, а не эффект причинного вмешательства.

Контролируйте область применения явно: диапазон концентраций, температур, типов сырья и приборов, покрытие комбинаций факторов, расстояние до обучающих рецептур и дрейф распределения. Простой диапазон по каждому фактору не обнаруживает недопустимую комбинацию внутри отдельных диапазонов. В отчёте показывают хотя бы флаг «вне изученного плана», диапазон и число партий, на которых оценивалась точность.

Прогнозный интервал для **нового результата** должен учитывать вариацию между партиями и ошибку наблюдения, а не только неопределённость среднего прогноза. Его покрытие проверяют на независимых партиях; метод построения может требовать обменности или других предпосылок, которые нарушаются при смене прибора или режима. Если надёжных интервалов нет, обоснованнее указать диапазон ошибок по тестовым группам и ограничение выборки.

## 8. Активное обучение и следующий опыт

После проверки модель может предложить информативную рецептуру. Возможные критерии — ожидаемое улучшение целевого свойства, уменьшение неопределённости или разведка плохо изученного участка. Любой из них ограничивают технологическими диапазонами, безопасностью, стоимостью и доступностью сырья. Если модель уверена по ошибочной причине, выбор только «лучшего предсказания» может зациклить исследование. Часть опытов оставляют для проверки и репликации.

```text
Цель и ограничения → кандидаты рецептур → модель + неопределённость
→ экспертный выбор → синтез и измерение → запись новой партии
→ обновление модели → проверка критерия остановки
```

Это **активное обучение / последовательный дизайн**: выбирают, какое следующее измерение запросить, чтобы улучшить прогноз или решение. Один простой учебный критерий для максимизации свойства: $a(x)=\hat y(x)+\lambda u(x)$, где $u(x)$ — оценка неопределённости и кандидаты уже отфильтрованы по допустимым условиям. Например, прогнозы A: $95\pm2$ и B: $90\pm8$ дают при $\lambda=1$ оценки 97 и 98; критерий выберет B ради проверки менее изученного участка. Это **условный** расчёт: знак «±» здесь обозначает выбранный показатель неопределённости, а не проверенный 95%-й интервал; при плохо калиброванном $u$ решение может быть ошибочным. Для практики добавляют репликацию, проверку крайних режимов и критерий остановки.

Важно зафиксировать момент решения. Если условия синтеза выбирают до приготовления, спектр *ещё не изготовленной* партии нельзя использовать как вход модели. После синтеза её спектр уже может помочь решить, какой образец направить на дорогое испытание. Это две разные задачи с разными доступными признаками.

## 9. Нейронная сеть: что конкретно она вычисляет

Для строки числовых входов $x\in\mathbb R^d$ небольшая сеть с одним скрытым слоем вычисляет $h=\operatorname{ReLU}(W_1x+b_1)$, затем $\hat y=W_2h+b_2$. Нелинейность ReLU зануляет отрицательные входы нейронов и позволяет модели описывать кусочно-нелинейную связь. Для регрессии можно минимизировать $L=\frac1n\sum_i(y_i-\hat y_i)^2$; обратное распространение вычисляет производные потерь по весам, оптимизатор обновляет веса по направлению уменьшения $L$. Для класса нужен другой выход и функция потерь. Обучающие *эпохи* повторно используют те же объекты; 500 эпох не означают 500 независимых опытов.

Для RGB-признаков можно рассмотреть сеть **3 → 8 → 1** с $3\cdot8+8+8\cdot1+1=41$ обучаемым параметром. Линейной регрессии с тремя входами достаточно четырёх коэффициентов с intercept. Это не довод в пользу той или другой модели без одинаковой проверки на новых независимых объектах. В табличной задаче с малым числом строк уместно начать с Ridge и бустинга. Масштабирование признаков, отбор эпох/гиперпараметров и обучение сети должны происходить *внутри тренировочных групп*; для честной оценки нужна удержанная группа. Предобученные веса полезны только при понятном происхождении исходных данных и отсутствии пересечения с тестом.

Сеть на изображении может учиться по пространственному расположению пикселей, сеть на спектре — по соседним каналам, графовая сеть — по атомам и связям. Однако готовые RGB-значения уже являются тремя признаками, а не полными изображениями. Создание свёрточной модели из таблицы RGB не добавляет потерянную пространственную информацию. Технические фотографии одной кюветы остаются зависимыми наблюдениями.

### Учебный набор pH по RGB

В [pH-recognition](https://www.kaggle.com/datasets/robjan/ph-recognition) автор предлагает прогнозировать **pH по значениям RGB цвета**. Это задача регрессии с тремя входами; наличие слова *image* в описании не означает, что в наборе хранятся исходные изображения. Начните с проверки реальных имён столбцов, единицы строки, пропусков, диапазонов RGB и pH. Сравните константу, Ridge, градиентный бустинг и, как необязательный опыт, малую сеть 3 → 8 → 1. MAE выражают в единицах pH. Ошибки следует показывать и по диапазонам pH: усреднение может скрыть плохое качество в нужной области.

Авторское описание набора не задаёт проверенный протокол съёмки, идентификаторы независимых растворов, освещения и приборов. Если их нет и в файлах, случайное разбиение строк оценивает перенос лишь на похожие записи **этого** набора. Оно не доказывает качество на новом телефоне, другом индикаторе или иной лаборатории. Для такой проверки нужно собрать новые растворы и независимые сессии съёмки с эталонным pH-метром, зафиксировать освещение, баланс белого и калибровку, а затем отложить целые сессии/приборы. Это предложение учебного дизайна, а не утверждение о происхождении строк Kaggle.

### Ноутбук о липофильности как разбор проверки модели

В [Physical Chemistry – Lipophilicity](https://www.kaggle.com/code/mmelahi/physical-chemistry-lipophilicity) прогнозируют экспериментальный $\log D$ при pH 7,4. Ноутбук загружает молекулярные дескрипторы, использует SVR, сеть Keras и последующие модели на представлении сети. В опубликованной версии **до `train_test_split`** применяются `StandardScaler` и `KernelPCA` ко всей таблице дескрипторов, а после разделения автор снова объединяет преобразованные `X_train` и `X_test` для масштабирования и `KernelPCA`. Таким образом, распределение тестовых признаков участвует в подготовке модели. Такое преобразование без меток тоже влияет на оценку переноса. Ноутбук полезен именно как материал для аудита, а его численную точность нельзя без поправки процедуры считать независимой проверкой.

Корректная учебная последовательность: сначала закрепить идентификаторы молекул и выбрать тест под будущую задачу; затем раздельно подбирать импутацию, масштаб, сокращение размерности и модель на тренировочной части; внутри CV повторять все `fit` только на её обучающих складках; единожды оценить заранее выбранный конвейер на удержанных молекулах. Для переноса на **новые химические серии** случайного деления молекул может быть недостаточно: полезна проверка по каркасу/семейству структур, если структуру можно достоверно восстановить. Логарифмическое распределение $\log D$ при заданном pH не следует отождествлять с безусловным $\log P$.

## 10. Обучение с подкреплением: решение во времени

Пусть процесс получения покрытия управляется во времени. На шаге $t$ состояние $s_t$ содержит доступные измерения (например, температуру, оценку толщины, остаток реагента); действие $a_t$ задаёт допустимое изменение мощности или расхода; переход $s_{t+1}$ зависит от предыдущего состояния, действия и неконтролируемого шума. Вознаграждение $r_t$ может отражать качество конечной плёнки с расходом энергии и штрафом за нарушение технологических ограничений. Студент должен отдельно указать, какие величины измеряются онлайн и какие известны лишь после процесса: скрытая истинная толщина не может быть входом регулятора без датчика или оценивателя.

Цель политики $\pi(a\mid s)$ — максимизировать ожидаемую сумму $\mathbb E_\pi[\sum_{t=0}^{T}\gamma^t r_t]$, где $\gamma$ задаёт вес отдалённых последствий. На двухшаговом **условном** примере быстрое нагревание даёт сейчас +3, но следующий лучший исход −6, а плавное нагревание даёт сейчас 0 и затем +4. При $\gamma=0{,}9$: $Q(\text{быстро})=3+0{,}9(-6)=-2{,}4$ и $Q(\text{плавно})=0+0{,}9\cdot4=3{,}6$. Алгоритм должен учитывать последующее состояние, а не выбирать действие по мгновенному отклику. Числа иллюстрируют **постановку**, а не безопасный режим реального оборудования.

| Подход | Что выбирается | Где обратная связь | Характерная проверка |
|---|---|---|---|
| Регрессия | Прогноз свойства для известных входов | Метка образца | Новые партии или химические серии |
| Активное обучение | Следующий опыт/объект для измерения | Итог нового опыта | Качество решений после серии опытов |
| RL / управление | Действие на каждом шаге процесса | Траектория и итоговый результат | Симулятор, ограничения, затем контролируемый пилот |

Для реального RL недостаточно таблицы «рецепт → итоговое качество»: нужны траектории состояний, действий, времени и исходов, описание допустимых воздействий, ограничений и достоверная среда для предварительной проверки. Исторические данные могут не содержать последствий альтернативных действий. Поэтому проверка на симуляторе, анализ сдвига между симулятором и установкой, независимая проверка оценок и надзор оператора предшествуют любому эксперименту с онлайн-управлением. Выбор одного следующего статического синтеза, описанный в разделе 8, не превращается в RL от добавления слова «награда».

## 11. Мини-проект: от прогноза к проверяемому решению

На обзорном уровне полезно различать supervised прогноз свойства, unsupervised представление структуры, активный выбор следующего эксперимента и последовательное управление. Нейронная сеть — возможный вид модели внутри этих задач, а не отдельная цель исследования.

Возьмите паспорт задачи из лекции 11. Сравните baseline и две осмысленные модели на одной групповой схеме. Если есть спектры, сравните Ridge и PLS; если табличные условия синтеза — Ridge, лес и бустинг с ограниченной сложностью. Отдельно исследуйте PCA или кластеры, если научный вопрос требует описания структуры. Представьте число независимых партий, ошибку на новых группах, график ошибок, один пример разногласия моделей и границы интерполяции.

Последний раздел проекта — **один конкретный следующий опыт**: рецептура в разрешённом диапазоне, ожидаемое свойство, причина выбора, измеряемый исход, критерий принятия/опровержения, технические и независимые повторы. Укажите, что будете делать, если результат противоречит модели. Если данных ещё мало, предложите небольшую сбалансированную серию и заранее зафиксируйте план проверки вместо оптимизации по случайному шуму.

Примеры предметных задач: диаметр капель природных масел, стабильность микроэмульсии, отклик спектра оксидного покрытия, свойства магнитных наночастиц, сорбция на мезопористом SiO₂, каталитическая активность новой партии, качество тонкой плёнки. У каждой задачи своё определение независимой единицы и допустимого прогноза.
