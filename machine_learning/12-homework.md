# Домашнее задание. Выбор метода и следующего эксперимента

Практика к [лекции 12](12-ml-methods_and_experiment.md) «Машинное обучение: выбор метода и следующего эксперимента». Задачи продолжают тему квантовых точек и нанокомпозитов, но учебные данные **искусственные**. В отдельном опыте допустимо использовать свои спектры, если подготовлены партии, паспорт съёмки и разбиение до настройки модели.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(120)
wl_nm = np.arange(500, 601, 10)
rows, spectra = [], []
for campaign in range(8):
    campaign_shift = rng.normal(0, 2)
    for batch in range(6):
        polymer_pct = float((campaign + batch) % 4)
        temp_c = 75 + 10 * ((2 * campaign + batch) % 4)
        peak_nm = 540 + 2.2 * polymer_pct + 0.06 * (temp_c - 90)
        curve = (0.10 + np.exp(-0.5 * ((wl_nm - peak_nm) / 16)**2)
                 + rng.normal(0, 0.025, wl_nm.size))
        retention = (63 + 3.2 * polymer_pct - 0.14 * abs(temp_c - 90)
                     + 5 * curve.max() + campaign_shift + rng.normal(0, 2))
        rows.append((f"C{campaign}-B{batch}", campaign, polymer_pct,
                     temp_c, retention))
        spectra.append(curve)
table = pd.DataFrame(rows, columns=["batch_id", "campaign_id", "polymer_pct",
                                    "temp_c", "retention_pct"])
X_spectra = np.asarray(spectra)
```

Каждая строка — независимо изготовленная партия нанокомпозита. Спектр зарегистрирован **после синтеза, но до** испытания сохранения фотолюминесценции через неделю. Сетка `wl_nm` и строки `X_spectra` имеют одинаковый порядок. Храните `batch_id` при каждом преобразовании массива; проверьте 48 уникальных партий, восемь кампаний и форму спектральной матрицы `(48, 11)`. Это искусственная демонстрация, а не измеренные спектры реальных квантовых точек.

**Два момента решения:** рецепт (`polymer_pct`, `temp_c`) доступен **до синтеза** и нужен для выбора трёх новых опытов. Первичный спектр доступен **после синтеза** и может помочь предсказать результат недельного испытания уже полученной партии. Нельзя подавать спектр будущей партии в первый прогноз. Эти две задачи сравнивайте с соответствующими допустимыми признаками.

**Порядок проверки:** кампании 0–6 составляют разработку (42 партии); кампания 7 — удержанный финальный тест (6 партий). В разработке используйте одни и те же семь складок `GroupKFold(n_splits=7)`, удерживая по одной кампании в каждой. До завершения выбора всех моделей, настроек, правила выбора и порога полезной ошибки **не смотрите целевые значения и рисунки кампании 7**, не используйте её признаки для PCA, кластеров, важности, настройки или выбора трёх опытов. Задания 2–7 выполняются на разработке; один финальный блок после них открывает тест единожды. Ошибка кандидата на складках, по которым выбирались его настройки и модель, помогает сделать выбор, но не является независимой оценкой качества выбранной процедуры. MAE выражайте в процентных пунктах сохранения фотолюминесценции, а не в процентах относительной ошибки.

### 2. Лестница моделей

**Контекст:** Доступно всего 42 независимые партии для обучения.

**Задача:** На одних и тех же складках разработки сравните `DummyRegressor`, Ridge по **рецептуре** (`polymer_pct`, `temp_c`) и Ridge по **только спектральным каналам**. ### 5. Дерево, важность и область применимости

Встроенную случайную раннюю остановку отключите либо обеспечьте групповой способ её оценки. Вместо трека A или B можно выполнить [практикум по экспериментальному плану и регрессии](../projects/regression_cases/assignment.md): модель на варианте 3 или 6, аудит второго варианта и план новых независимых опытов. Для этого задания он занимает место **одного** практического трека; рубрика выше применяется к работе по лекции 12 в целом. Отдельная рубрика в практикуме предназначена для его самостоятельной сдачи. Не приписывайте историческим таблицам неизвестные идентификаторы партий и не переносите их условную проверку на будущие синтезы.
