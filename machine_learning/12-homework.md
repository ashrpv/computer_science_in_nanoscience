# Домашнее задание. Выбор метода и следующего эксперимента

Практика к [лекции 12](12-ml-methods_and_experiment.md) «Машинное обучение: выбор метода и следующего эксперимента». Задачи продолжают тему квантовых точек и нанокомпозитов, но учебные данные **искусственные**. В отдельном опыте допустимо использовать свои спектры, если подготовлены партии, паспорт съёмки и разбиение до настройки модели.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(120)
wl_nm = np.arange(500, 601, 10)
rows, spectra = [], []
for campaign in range(8):
    campaign_shift = rng.normal(0, 2)
    for batch in range(6):
        polymer_pct = float((campaign + batch) % 4)
        temp_c = 75 + 10 * ((2 * campaign + batch) % 4)
        peak_nm = 540 + 2.2 * polymer_pct + 0.06 * (temp_c - 90)
        curve = (0.10 + np.exp(-0.5 * ((wl_nm - peak_nm) / 16)**2)
                 + rng.normal(0, 0.025, wl_nm.size))
        retention = (63 + 3.2 * polymer_pct - 0.14 * abs(temp_c - 90)
                     + 5 * curve.max() + campaign_shift + rng.normal(0, 2))
        rows.append((f"C{campaign}-B{batch}", campaign, polymer_pct,
                     temp_c, retention))
        spectra.append(curve)
table = pd.DataFrame(rows, columns=["batch_id", "campaign_id", "polymer_pct",
                                    "temp_c", "retention_pct"])
X_spectra = np.asarray(spectra)
```

Каждая строка — независимо изготовленная партия нанокомпозита. Спектр зарегистрирован **до** испытания сохранения фотолюминесценции через неделю. Сетка `wl_nm` и строки `X_spectra` имеют одинаковый порядок. Храните `batch_id` при каждом преобразовании массива.

### Подготовка: две точки принятия решения

При запуске проверьте `len(table) == 48`, `table.batch_id.is_unique`, `X_spectra.shape == (48, len(wl_nm))`, отсутствие `NaN` и шесть партий в каждой из восьми кампаний. Не сортируйте `table` отдельно от `X_spectra`: спектр строки `i` принадлежит ровно `table.iloc[i]`. Один способ сохранить связь — сделать столбцы `signal_500`, `signal_510`, …, `signal_600` из массива и присоединить их к копии `table` **без смены порядка строк**. Значения сигнала здесь условные; не назначайте им единицу физической интенсивности, не заданную генератором.

| Решение | Когда принимают | Допустимые входы | Что предсказывают |
|---|---|---|---|
| Какой состав синтезировать | До изготовления партии | `polymer_pct`, `temp_c` | Сохранение фотолюминесценции через неделю, % |
| Какую готовую партию направить на недельное испытание | После съёмки первичного спектра | Состав, температура и спектр этой партии | Тот же недельный отклик, % |

Подбор трёх следующих рецептур в блоке 2 опирается на **первую** постановку. Модель со спектром можно использовать уже после синтеза для второй постановки. Ответ `retention_pct` и `campaign_id` не входят в признаки ни там, ни там. Примеры конвейеров приведены в [лекции 12](12-ml-methods_and_experiment.md#3-pls-для-спектров), зависимости пакетов — в [окружении курса](../requirements.txt).

Код агента RL не требуется.

## Что сдать и как оценивать

Notebook с неизменяемым удержанным тестом синтетического блока, таблицей моделей и ошибок по кампаниям, ручным шагом бустинга, рисунком PCA, таблицей устойчивости кластеров и протоколом трёх следующих синтезов. Таблица сравнения содержит `момент прогноза`, `входы`, `модель`, `настройка`, `MAE по каждой кампании 0–6`, `среднее MAE разработки` и `MAE на кампании 7`; на кампании 7 не подбирают настройки. Для **одного выбранного** реального трека сдайте таблицу источника/столбцов/разбиения/результатов или ограниченную локальную замену при недоступных внешних файлах; добавьте аудит ноутбука либо схемы ошибки и описание последовательной задачи. Код нейронной сети и RL необязателен.

Критерии: проверка по независимым единицам и отсутствие утечек — 30%; сравнение методов и объяснение шага бустинга — 25%; исследовательское решение и план синтезов — 20%; реальный трек с честной трактовкой пределов проверки — 15%; аудит ноутбука и постановка последовательного управления — 10%. Сложная модель без корректного теста не даёт зачёта за проверку.

## Самостоятельная работа: модель как инструмент выбора

Без новых файлов нарисуйте две схемы применения к тем же искусственным партиям: выбор рецептуры **до** синтеза по двум факторам и выбор дорогостоящего недельного испытания **после** первичного спектра. Для каждой подпишите момент доступа к спектру, численную цель, независимую единицу будущей проверки и два возможных источника ошибочного решения. Если хотите проверить нейросеть, добавьте небольшой `MLPRegressor(hidden_layer_sizes=(8,), random_state=120)` к соответствующей лестнице моделей с масштабированием внутри конвейера и теми же семью складками; сравните её с Ridge и бустингом, а не только между вариантами сети. Это расширение не требуется для основной сдачи и не заменяет независимую кампанию 7.
