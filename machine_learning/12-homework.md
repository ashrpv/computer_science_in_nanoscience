```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(120)
wl_nm = np.arange(500, 601, 10)
rows, spectra = [], []
for campaign in range(8):
    campaign_shift = rng.normal(0, 2)
    for batch in range(6):
        polymer_pct = float((campaign + batch) % 4)
        temp_c = 75 + 10 * ((2 * campaign + batch) % 4)
        peak_nm = 540 + 2.2 * polymer_pct + 0.06 * (temp_c - 90)
        curve = (0.10 + np.exp(-0.5 * ((wl_nm - peak_nm) / 16)**2)
                 + rng.normal(0, 0.025, wl_nm.size))
        retention = (63 + 3.2 * polymer_pct - 0.14 * abs(temp_c - 90)
                     + 5 * curve.max() + campaign_shift + rng.normal(0, 2))
        rows.append((f"C{campaign}-B{batch}", campaign, polymer_pct,
                     temp_c, retention))
        spectra.append(curve)
table = pd.DataFrame(rows, columns=["batch_id", "campaign_id", "polymer_pct",
                                    "temp_c", "retention_pct"])
X_spectra = np.asarray(spectra)
```

Каждая строка — независимо изготовленная партия нанокомпозита. Спектр зарегистрирован **до** испытания сохранения фотолюминесценции через неделю. Сетка `wl_nm` и строки `X_spectra` имеют одинаковый порядок. Храните `batch_id` при каждом преобразовании массива.
