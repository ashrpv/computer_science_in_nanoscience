# Домашнее задание. Выбор метода и следующего эксперимента

Практика к [лекции 12](12-ml-methods_and_experiment.md) «Машинное обучение: выбор метода и следующего эксперимента». Задачи продолжают тему квантовых точек и нанокомпозитов, но учебные данные **искусственные**. В отдельном опыте допустимо использовать свои спектры, если подготовлены партии, паспорт съёмки и разбиение до настройки модели.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(120)
wl_nm = np.arange(500, 601, 10)
rows, spectra = [], []
for campaign in range(8):
    campaign_shift = rng.normal(0, 2)
    for batch in range(6):
        polymer_pct = float((campaign + batch) % 4)
        temp_c = 75 + 10 * ((2 * campaign + batch) % 4)
        peak_nm = 540 + 2.2 * polymer_pct + 0.06 * (temp_c - 90)
        curve = (0.10 + np.exp(-0.5 * ((wl_nm - peak_nm) / 16)**2)
                 + rng.normal(0, 0.025, wl_nm.size))
        retention = (63 + 3.2 * polymer_pct - 0.14 * abs(temp_c - 90)
                     + 5 * curve.max() + campaign_shift + rng.normal(0, 2))
        rows.append((f"C{campaign}-B{batch}", campaign, polymer_pct,
                     temp_c, retention))
        spectra.append(curve)
table = pd.DataFrame(rows, columns=["batch_id", "campaign_id", "polymer_pct",
                                    "temp_c", "retention_pct"])
X_spectra = np.asarray(spectra)
```

Каждая строка — независимо изготовленная партия нанокомпозита. Спектр зарегистрирован **после синтеза, но до** испытания сохранения фотолюминесценции через неделю. Сетка `wl_nm` и строки `X_spectra` имеют одинаковый порядок. Храните `batch_id` при каждом преобразовании массива; проверьте 48 уникальных партий, восемь кампаний по шесть партий, отсутствие `NaN` и форму спектральной матрицы `(48, 11)`. Не сортируйте `table` отдельно от `X_spectra`: спектр строки `i` принадлежит `table.iloc[i]`. При необходимости соедините спектр с метаданными в одной таблице с именами каналов `signal_500`, …, `signal_600`. Это искусственная демонстрация, а не измеренные спектры реальных квантовых точек.

**Два момента решения:** рецепт (`polymer_pct`, `temp_c`) доступен **до синтеза** и нужен для выбора трёх новых опытов. Первичный спектр доступен **после синтеза** и может помочь предсказать результат недельного испытания уже полученной партии. Нельзя подавать спектр будущей партии в первый прогноз. Эти две задачи сравнивайте с соответствующими допустимыми признаками.

**Порядок проверки:** кампании 0–6 составляют разработку (42 партии); кампания 7 — удержанный финальный тест (6 партий). В разработке используйте одни и те же семь складок `GroupKFold(n_splits=7)`, удерживая по одной кампании в каждой. До завершения выбора всех моделей, настроек, правила выбора и порога полезной ошибки **не смотрите целевые значения и рисунки кампании 7**, не используйте её признаки для PCA, кластеров, важности, настройки или выбора трёх опытов. Задания 2–7 выполняются на разработке; один финальный блок после них открывает тест единожды. Ошибка кандидата на складках, по которым выбирались его настройки и модель, помогает сделать выбор, но не является независимой оценкой качества выбранной процедуры. MAE выражайте в процентных пунктах сохранения фотолюминесценции, а не в процентах относительной ошибки.

Примеры конвейеров есть в [лекции 12](12-ml-methods_and_experiment.md#3-pls-для-спектров), зависимости пакетов — в [окружении курса](../requirements.txt). Сохраните генератор и проверки в начале notebook, чтобы повторный запуск с начала не зависел от ручного состояния ячеек.

Если в ноутбуке встречается название «Gradient Boosting of Keras Model with SVC», посмотрите фактический класс модели в соответствующей ячейке. Разделите *использование представления нейросети с последующим SVR* и *градиентный бустинг деревьев*: одинаковое слово в заголовке не делает алгоритмы тождественными.

### 9. Что потребовалось бы для управления процессом?

Для выбранной научной установки опишите одно доступное онлайн состояние, одно допустимое действие, источник следующего наблюдения, отложенное вознаграждение и жёсткое ограничение. На условных числах лекции при $\gamma=0{,}9$ пересчитайте суммарную ценность быстрого и плавного нагревания. Объясните, почему таблицы RGB → pH и молекула → $\log D$ не дают траекторий действий для обучения политики и как вы сначала проверили бы политику, прежде чем применять её к установке. Код агента RL не требуется.

**Обязательное ядро:** задания 1–3, рецептурный Ridge и бустинг с ручным шагом из задания 5, задание 7, единая финальная проверка, **один** практический маршрут (A или B с данными либо планом при их недоступности; локальный C; полный исторический практикум) и краткая постановка из задания 9. Настройку и выбор методик в углублениях проводите только на разработке; если финальную кампанию описательно показываете на графике или рассчитываете для неё важность, делайте это уже после заморозки решения.

Сдайте notebook с генератором, проверками ID и разбиений, таблицей `момент прогноза`, `входы`, `модель`, `настройка`, MAE по **семи** проверочным кампаниям и средняя MAE разработки для каждого обязательного кандидата. Отдельно сохраните записанный **до теста** выбор двух моделей, ручной шаг бустинга и **одну** итоговую таблицу для шести партий кампании 7. Добавьте короткий протокол трёх следующих синтезов с прогнозами до синтеза. Для A/B сдайте таблицу источника, столбцов, разбиения и результатов или обоснованный план при недоступных файлах; для C — ограниченный результат из его условия; для полного исторического практикума — материалы из его условия. В рамках этой работы к выбранному маршруту применяется общая рубрика ниже. Завершите краткой постановкой последовательной задачи из задания 9.
