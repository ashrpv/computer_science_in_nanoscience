Создайте учебные данные один раз с фиксированным seed:

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(111)
rows = []
for campaign in range(12):
    day_shift = rng.normal(0, 4)
    for batch in range(4):
        oil = ["peach", "apricot"][(campaign + batch) % 2]
        squalene = float((campaign + 2 * batch) % 3)  # мас. %
        sonication = [5, 10, 15, 20][(campaign + batch) % 4]  # мин
        true_d = (155 - 6 * squalene - 1.1 * sonication
                  + (7 if oil == "apricot" else 0) + day_shift)
        batch_id = f"C{campaign:02d}-B{batch}"
        for technical_repeat in range(3):
            rows.append((batch_id, campaign, oil, squalene, sonication,
                         technical_repeat, true_d + rng.normal(0, 2)))
data = pd.DataFrame(rows, columns=["batch_id", "campaign_id", "oil",
                                   "squalene_pct", "sonication_min",
                                   "technical_repeat", "diameter_nm"])
```

`campaign_id` обозначает общий день приготовления четырёх **независимых партий**. Три отсчёта внутри `batch_id` — технические повторы. Зависимость отклика от факторов задана генератором только для проверки учебного анализа, а не как установленный закон для эмульсий.
