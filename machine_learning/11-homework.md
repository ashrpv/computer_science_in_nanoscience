# Домашнее задание к лекции 11. Проверка прогноза новых партий

Связано с [лекцией 11](11-ml-problem_and_validation.md). Задача: до приготовления наноэмульсии из природного масла предсказать средний диаметр капель (нм) по рецептуре. Все данные ниже **искусственные**; коэффициенты генератора не описывают реальные эмульсии. Можно использовать собственный набор по другой научной теме, если явно описаны единица прогноза, уровни повторов и схема независимой проверки.

## Данные и рамка решения

Выполните генератор один раз. Он создаёт 12 дней (`campaign_id`), четыре независимо приготовленные партии в каждый день (`batch_id`) и три технических отсчёта в партии. Две последние кампании предназначены для финального теста и не участвуют в выборе признаков, метода, порога или seed.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(111)
rows = []
for campaign in range(12):
    day_shift = rng.normal(0, 4)
    for batch in range(4):
        oil = ["peach", "apricot"][(campaign + batch) % 2]
        squalene = float((campaign + 2 * batch) % 3)  # мас. %
        sonication = [5, 10, 15, 20][(campaign + batch) % 4]  # мин
        mean_d = (155 - 6 * squalene - 1.1 * sonication
                  + (7 if oil == "apricot" else 0) + day_shift
                  + rng.normal(0, 2))
        for repeat in range(3):
            rows.append((f"C{campaign:02d}-B{batch}", campaign, oil,
                         squalene, sonication, repeat,
                         mean_d + rng.normal(0, 2)))
raw = pd.DataFrame(rows, columns=["batch_id", "campaign_id", "oil",
                                  "squalene_pct", "sonication_min",
                                  "repeat", "diameter_nm"])
```

Допущение для практики: будущие партии будут готовиться **в новые дни** при том же приборе и в пределах заданных рецептур. Стоимость ошибки относительно порога можно обсудить условно, но не выдавайте учебные величины за реальные технологические нормативы.

Пропущенные значения или новый протокол измерения потребовали бы записанного правила обработки **до** расчёта цели.
