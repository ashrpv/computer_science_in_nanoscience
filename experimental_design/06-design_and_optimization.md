Цель: выбрать план под научный вопрос, оценить локальную модель и предложить режим для независимого подтверждения. Предполагается знакомство с регрессией и ANOVA; их основы здесь не повторяются.

## 1. Цель, факторы и надёжность

До опытов определяют отклик и его единицы, факторы и диапазоны, допустимые сочетания, независимую единицу и критерий успеха. Скрининг ищет важные факторы, сравнение оценивает различия заданных режимов, оптимизация ищет допустимое сочетание с лучшим откликом.

| Приём | Назначение | Ограничение |
|---|---|---|
| Рандомизация | Ослабить связь факторов с дрейфом времени и другими неучтёнными трендами | Не устраняет дрейф физически |
| Блокирование | Учесть известную неоднородность: день, сырьё, оператор | Блок должен быть учтён и в анализе |
| Независимые повторы | Оценить чистую ошибку процесса | Повторное измерение одной пробы их не заменяет |

Для непрерывного фактора используют кодирование:

$$x_i = \frac{X_i-X_{0i}}{\Delta X_i}.$$

`−1` и `+1` соответствуют выбранным нижней и верхней границам. Кодирование не делает опасную или технически невозможную комбинацию допустимой.

## 2. Полный факторный план и взаимодействие

План $2^k$ содержит все комбинации двух уровней `k` факторов. Для трёх факторов это восемь комбинаций. Полная модель:

$$y=\beta_0+\beta_A A+\beta_B B+\beta_C C+\beta_{AB}AB+\beta_{AC}AC+\beta_{BC}BC+\beta_{ABC}ABC+\varepsilon.$$

При кодировании ±1 разность средних на верхнем и нижнем уровнях фактора равна удвоенному соответствующему коэффициенту в ортогональном полном плане. Взаимодействие означает, что эффект одного фактора зависит от уровня другого. Если сохраняется `A:B`, в иерархической модели сохраняют также `A` и `B`.

Восемь опытов для восьми коэффициентов дают насыщенную модель без остаточных степеней свободы. Для оценки чистой ошибки нужны независимые повторы.

```python
from itertools import product
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(42)
design = pd.DataFrame(product([-1, 1], repeat=3), columns=["A", "B", "C"])
runs = pd.concat([design, design], ignore_index=True)
runs = runs.sample(frac=1, random_state=42).reset_index(drop=True)
runs["run_id"] = np.arange(1, len(runs) + 1)
# Искусственные отклики для 16 независимых опытов.
runs["y"] = (50 + 3 * runs["A"] - 2 * runs["B"] + runs["C"]
             + 4 * runs["A"] * runs["B"] + rng.normal(0, 0.8, len(runs)))
factorial_model = smf.ols("y ~ A * B * C", data=runs).fit()
print(factorial_model.params)
assert factorial_model.df_resid == 8
```

В реальной работе таблицу рандомизируют **до выполнения опытов**. Результаты присоединяют по `run_id`; сортировать план после измерений недостаточно для рандомизации эксперимента.

## 3. Дробные планы и смешение эффектов

Полуреплика $2^{3-1}$ с генератором `C = AB` содержит четыре опыта. Определяющее соотношение `I = ABC` даёт смешение `A ↔ BC`, `B ↔ AC`, `C ↔ AB`. Такие эффекты нельзя разделить по этим данным без дополнительных опытов или предположений.

| Разрешение | Что смешивается в регулярном двухуровневом плане |
|---|---|
| III | Главные эффекты могут смешиваться с двухфакторными взаимодействиями |
| IV | Главные эффекты отделены от двухфакторных, но двухфакторные смешаны друг с другом |
| V | Главные эффекты отделены от двух- и трёхфакторных; двухфакторные отделены друг от друга, но могут смешиваться с трёхфакторными |

Экономия опытов требует содержательной гипотезы о малых взаимодействиях. Значимый составной эффект нельзя автоматически назвать эффектом одного фактора.

## 4. Кривизна и центрально-композиционный план

Повторы в центре дают чистую ошибку и позволяют обнаружить общую кривизну относительно факторной части. Одних центральных точек недостаточно для раздельной оценки всех квадратов факторов.

Для локальной поверхности отклика используют:

$$\hat y=\beta_0+\sum_i\beta_i x_i+\sum_i\beta_{ii}x_i^2+\sum_{i<j}\beta_{ij}x_ix_j.$$

Центрально-композиционный план (CCD) объединяет факторную часть, звёздные точки и центральные повторы. Для ротатабельного CCD на полной факторной части расстояние звёздных точек $\alpha=(2^k)^{1/4}$. В CCC они выходят за факторный куб, CCI сжимает факторную часть под заданные границы, CCF ставит звёздные точки на гранях (`α = 1`). CCF в общем случае не ротатабелен.

## 5. Квадратичная модель и оптимизация в Python

Следующий самостоятельный пример использует двухфакторный CCF с пятью независимыми центральными повторами. Пределы заданы в кодированных единицах.

```python
from itertools import product
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
from scipy.optimize import differential_evolution

rng = np.random.default_rng(2026)
points = (list(product([-1.0, 1.0], repeat=2))
          + [(-1, 0), (1, 0), (0, -1), (0, 1)] + [(0, 0)] * 5)
df = pd.DataFrame(points, columns=["x1", "x2"])
df = df.sample(frac=1, random_state=2026).reset_index(drop=True)
df["y"] = (80 + 6 * df.x1 + 4 * df.x2 - 8 * df.x1**2
           - 5 * df.x2**2 - df.x1 * df.x2 + rng.normal(0, 0.3, len(df)))
surface = smf.ols("y ~ x1 + x2 + I(x1**2) + I(x2**2) + x1:x2", data=df).fit()

def predict_at(x):
    row = pd.DataFrame({"x1": [x[0]], "x2": [x[1]]})
    return float(surface.predict(row).iloc[0])

optimum = differential_evolution(
    lambda x: -predict_at(x), bounds=[(-1, 1), (-1, 1)], rng=42
)
assert optimum.success
print("Кандидат:", optimum.x, "Прогноз:", -optimum.fun)
candidate = pd.DataFrame([optimum.x], columns=["x1", "x2"])
print(surface.get_prediction(candidate).summary_frame())
```

Формульная модель `statsmodels` при прогнозе получает таблицу с теми же именами факторов. Оптимизатор минимизирует функцию, поэтому для максимума используется знак минус.

Перед принятием результата проверяют остатки, неадекватность модели относительно чистой ошибки (lack of fit), интервалы и положение кандидата внутри области плана. Интервал среднего отклика и интервал нового наблюдения различаются. Интервалы, вычисленные после выбора оптимума на тех же данных, сами по себе не учитывают всю неопределённость поиска. Кандидата проверяют независимыми опытами.

## 6. Смеси и ограниченная область

Для смеси доли связаны: $\sum_i x_i=1$, $x_i\geq0$. Увеличение одной доли требует уменьшить другие. Модель Шеффе второго порядка:

$$E(y)=\sum_i\beta_i x_i+\sum_{i<j}\beta_{ij}x_ix_j.$$

Свободный интерсепт вместе со всеми долями линейно зависим, поэтому в этой записи он отсутствует. Для трёх компонентов область — треугольник; simplex-centroid включает вершины, центры рёбер и общий центр. Технологические ограничения могут исключать значительную часть треугольника.

До выбора плана формируют допустимый набор кандидатов: учитывают границы, сумму ресурсов, совместимость и дискретные настройки. Затем проверяют ранг матрицы модели и точность прогнозов. Потеря ортогональности ведёт к корреляции оценок.

## 7. D-оптимальность и несколько откликов

D-оптимальный план для заданной линейной модели выбирает точки, увеличивающие $\det(X^TX)$, то есть уменьшающие обобщённую дисперсию коэффициентов при стандартной модели ошибки. Критерий зависит от модели и набора кандидатов; он не гарантирует пригодность любой более сложной модели и не отменяет повторов для оценки ошибки.

Если нужно одновременно повысить выход и снизить энергозатраты, единственного лучшего решения может не быть. Граница Парето содержит решения, которые нельзя улучшить по одному критерию без ухудшения другого. Альтернатива — заранее согласованная функция желательности:

$$D=\left(\prod_{j=1}^{m}d_j^{w_j}\right)^{1/\sum_jw_j},\qquad 0\leq d_j\leq1,\quad w_j>0.$$

Неприемлемый отклик с `d = 0` обнуляет общую желательность. Пороги и веса определяют до поиска; в оптимизатор передают прогнозы моделей, физические границы и все ограничения.

## 8. Последовательный эксперимент и мини-проект

Сначала выполняют скрининг, затем уточняют направление улучшения, переносят область и строят локальную поверхность. Новый режим подтверждают независимыми опытами. Прогноз за границами плана остаётся гипотезой для следующего эксперимента.
