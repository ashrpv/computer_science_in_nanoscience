## 1. Мощность и объём выборки

`α` — вероятность ошибки I рода, `β` — ошибки II рода при конкретной альтернативе, `1 − β` — мощность. Она зависит от размера эффекта, числа независимых наблюдений, числа групп, уровня значимости и структуры дизайна. Параметр нецентральности обозначают `λ`, не `β`.

Для однофакторного сравнения независимых групп эффект Коэна задают как $f=\sqrt{\sum_i p_i(\mu_i-\mu)^2}/\sigma$. При соответствующей модели $\lambda=Nf^2$. Ожидаемый или минимально значимый эффект задают **до** анализа.

```python
from math import ceil
from statsmodels.stats.power import FTestAnovaPower

analysis = FTestAnovaPower()
power = analysis.power(effect_size=0.25, nobs=100, alpha=0.05, k_groups=5)
n_total = analysis.solve_power(effect_size=0.25, alpha=0.05,
                               power=0.80, k_groups=5)
n_per_group = ceil(n_total / 5)
n_with_losses = ceil(n_per_group / 0.9)
print(round(power, 3), round(n_total, 2), n_per_group, n_with_losses)
# примерно 0.466, 195.77, 40, 45
```

`nobs` — общий размер выборки. Получается 40 независимых наблюдений на группу, при ожидаемых 10% потерь — 45. Расчёт предполагает однофакторную модель с независимостью и общей дисперсией; он не переносится автоматически на вложенные или повторные измерения. Для сложного дизайна мощность можно оценивать моделированием всего эксперимента.

Если цель — сравнить две технологии, а каждую оценивают несколькими снимками *одной* партии, в формулу нельзя подставлять число снимков. Для эффекта технологии, назначенной на уровне партии, размер выборки задают партии; если назначения парные внутри дней, полезный сигнал и шум относятся к **разностям внутри дня**. При моделировании мощности генерируют день, отдельные партии, технические отсчёты и намеченное правило агрегации, после чего применяют ту же модель и критерий, что будут использованы в анализе. Такой расчёт явно проверяет, что даёт дополнительная партия по сравнению с ещё одним отсчётом.

## 2. Фиксированный и случайный фактор

Фиксированный фактор описывает конкретные интересующие уровни, например три технологии. Случайный фактор описывает вариацию популяции, из которой получены уровни, например независимые партии. Выбор определяется целью обобщения, а не числом уровней или способом записи столбца.

Однофакторная модель случайного интерсепта:

$$y_{ij}=\mu+a_i+\varepsilon_{ij},\qquad a_i\sim N(0,\sigma_a^2),\quad \varepsilon_{ij}\sim N(0,\sigma^2).$$

Случайные эффекты независимы между группами и от ошибок. Тогда $\mathrm{Var}(y)=\sigma_a^2+\sigma^2$, а внутриклассовая корреляция:

$$ICC=\frac{\sigma_a^2}{\sigma_a^2+\sigma^2}.$$

Большой ICC означает, что наблюдения внутри партии похожи и добавление технических повторов даёт меньше информации, чем добавление независимых партий.

Для одинаковых групп по `m` отсчётов приближённый коэффициент увеличения дисперсии **общего среднего** относительно независимых отсчётов равен $1+(m-1)ICC$. Например, при шести партиях по пять измерений и $ICC=0{,}6$ получаем $30/[1+4\cdot0{,}6]\approx8{,}8$ «эквивалентных» независимых отсчётов для среднего. Это не превращает шесть партий в девять независимых назначений технологии: для эффекта, назначенного каждой партии целиком, таких единиц всё равно шесть. Формула предполагает одинаковый размер групп и одинаковую парную корреляцию внутри каждой группы; при сложной иерархии или парном плане её не применяют без уточнения.

## 3. Метод моментов и MixedLM

В сбалансированном плане с `n` измерениями на группу:

$$E(MS_A)=\sigma^2+n\sigma_a^2,\qquad E(MS_E)=\sigma^2.$$

Отсюда $\hat\sigma_a^2=(MS_A-MS_E)/n$. Для `MS_A = 36.933`, `MS_E = 1.800`, `n = 3` получаем `11.711` и `ICC ≈ 0.867`. Отрицательная оценка методом моментов отражает слабую информацию о компоненте; отрицательная физическая дисперсия смысла не имеет.

Здесь `MS_E` оценивает вариацию *внутри* группы, а разность `MS_A − MS_E` выделяет межгрупповую часть. Например, если каждый образец партии трижды измеряли на одном приборе, большую оценку `11.711` нельзя объявлять приборной ошибкой. Если в нескольких группах по одному отсчёту, `MS_E` как внутри-групповую дисперсию оценить невозможно. Если оператор закреплён только за одной партией, его вклад тоже невозможно отделить от партии без изменения плана.

Самостоятельный пример на искусственных данных:

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
batch = np.repeat(np.arange(20), 6)
batch_effect = rng.normal(0, 3, 20)
df = pd.DataFrame({"batch": batch})
df["y"] = 50 + batch_effect[batch] + rng.normal(0, 1, len(df))
result = smf.mixedlm("y ~ 1", data=df, groups=df["batch"]).fit(reml=True)
assert result.converged
var_batch = float(result.cov_re.iloc[0, 0])
var_error = float(result.scale)
print(var_batch, var_error, var_batch / (var_batch + var_error))
```

REML учитывает оценивание фиксированных эффектов при оценке дисперсионных компонентов и поддерживает несбалансированность. Однако пропуски, мало групп и неверная ковариационная структура остаются проблемами. Проверяют сходимость, граничные оценки, остатки и устойчивость. Интервалы для дисперсии строят согласованным методом, например профилем правдоподобия или параметрическим bootstrap; разность двух интервалов не является интервалом разности.

Для этого кода ожидаемая между-партийная дисперсия в генераторе равна $3^2=9$, а остаточная — $1^2=1$, поэтому ориентир для ICC равен `0.9`; оценки на конечной выборке не обязаны совпадать с ним. Просмотрите разброс остатков внутри каждой партии, несколько самых необычных средних по партиям и стабильность результата после удаления *одной партии*; удалять точки только ради красивого остаточного графика нельзя. Если оценка компоненты стала нулевой или оптимизатор сообщил о проблеме сходимости, не превращайте такой результат в уверенное доказательство отсутствия вариации.

## 4. Скрещённые случайные факторы и EMS

При скрещивании каждый уровень A встречается с каждым B. Для сбалансированной модели с `a` и `b` уровнями и `n` повторами в ячейке:

$$y_{ijk}=\mu+a_i+b_j+(ab)_{ij}+\varepsilon_{ijk}.$$

| Источник | Ожидаемый средний квадрат | Знаменатель F при проверке соответствующей нулевой компоненты |
|---|---|---|
| A | $\sigma^2+n\sigma_{ab}^2+nb\sigma_a^2$ | $MS_{AB}$ |
| B | $\sigma^2+n\sigma_{ab}^2+na\sigma_b^2$ | $MS_{AB}$ |
| A × B | $\sigma^2+n\sigma_{ab}^2$ | $MS_E$ |
| Ошибка | $\sigma^2$ | — |

Знаменатель выбирают по совпадению EMS при нулевой гипотезе. Автоматически делить каждый эффект на `MSE` в этой модели неверно. Эти соотношения требуют указанного сбалансированного случайного дизайна и стандартных предпосылок; для иных моделей их выводят заново.

Проверка структуры предшествует таблице средних квадратов. Если операторы A1–A3 каждый измерили **все** партии B1–B4, оператор и партия скрещены: возможны эффекты A, B и A × B. Если каждому оператору досталась своя единственная партия, различия оператора и партии полностью смешаны, а формула скрещённого плана неприменима. При одном запуске на сочетание A × B вариация этого сочетания и ошибка запуска не разделяются; повтор на каждой паре уровней нужен, если требуется отдельно оценить оба компонента.

Для трёх скрещённых случайных факторов иногда используют приближение:

$$F_A\approx\frac{MS_A+MS_{ABC}}{MS_{AB}+MS_{AC}}.$$

Степени свободы числителя и знаменателя оценивают отдельно по Саттертуэйту:

$$\nu\approx\frac{(\sum_i c_iMS_i)^2}{\sum_i (c_iMS_i)^2/\nu_i}.$$

Это приближённая конструкция для конкретной комбинации независимых средних квадратов, а не универсальное правило для любой смешанной модели. Диаграммы включения источников помогают читать EMS, но не заменяют явную формулу модели.

## 5. Вложенность и смешанная модель

Партии внутри производителя вложены: партия A1 не существует у производителя B. Модель $y_{ijk}=\mu+A_i+B_{j(i)}+\varepsilon_{ijk}$ содержит `B(A)`, а не отдельные B и A × B.

В сбалансированном полностью случайном вложенном плане:

| Источник | df | EMS |
|---|---|---|
| A | $a-1$ | $\sigma^2+n\sigma_{B(A)}^2+bn\sigma_A^2$ |
| B(A) | $a(b-1)$ | $\sigma^2+n\sigma_{B(A)}^2$ |
| Ошибка | $ab(n-1)$ | $\sigma^2$ |

Здесь $F_A=MS_A/MS_{B(A)}$, $F_{B(A)}=MS_{B(A)}/MS_E$.

Если 12 производителей поставляют по четыре собственные партии, именовать партии просто `1`, `2`, `3`, `4` опасно: «партия 1» у двух производителей — разные объекты. Составной `batch_nested` в примере ниже сохраняет эту границу. Он не заменяет факт независимости изготовления: несколько навесок из одной поставки остаются навесками одной партии.

В следующем самостоятельном примере оба уровня случайные. Составной ID делает принадлежность партии явной.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

rng = np.random.default_rng(19)
rows = []
for manufacturer in range(12):
    u = rng.normal(0, 3)
    for batch in range(4):
        v = rng.normal(0, 1.5)
        for replicate in range(5):
            rows.append((manufacturer, batch, 20 + u + v + rng.normal(0, 0.5)))
nested = pd.DataFrame(rows, columns=["manufacturer", "batch", "y"])
nested["batch_nested"] = (nested.manufacturer.astype(str) + ":"
                           + nested.batch.astype(str))
fit = sm.MixedLM.from_formula(
    "y ~ 1", groups="manufacturer", re_formula="1",
    vc_formula={"batch": "0 + C(batch_nested)"}, data=nested,
).fit(reml=True)
assert fit.converged
print(fit.cov_re, fit.vcomp, fit.scale)
```

В генераторе заложены дисперсии `9` между производителями, `2.25` между партиями *одного* производителя и `0.25` между повторными измерениями партии. Поэтому для двух разных партий одного производителя ожидаемая ковариация равна `9`, а для двух отсчётов той же партии — `9 + 2.25 = 11.25`; общая дисперсия одного отсчёта — `11.5`. Так видно, почему «один ICC» недостаточен для всей трёхуровневой структуры. Оценки `fit` сравнивают с этими величинами как с ориентиром моделирования, а не как с известными параметрами реального материала.

Если научная цель — сравнить конкретные технологии, их включают как фиксированный эффект, сохраняя случайный интерсепт партии: например, `y ~ C(treatment)` с `groups=batch`. Идентифицируемость зависит от того, на каком уровне назначено воздействие. Сравнение разных фиксированных частей по правдоподобию обычно требует ML, а не сравнения REML-значений для разных фиксированных дизайнов.

План определяет и нужную случайную структуру: когда одна технология назначена целой партии, `batch_id` уникален внутри каждой технологии, и число партий в каждой технологии ограничивает точность сравнения. Когда обе технологии применены к разделённым навескам каждой партии, `batch_id` пересекает технологии и парность надо сохранить в модели. Одинаковая запись формулы фиксированного эффекта при этих двух планах скрывает разные ограничения на вывод.

## 6. Полный рандомизированный блочный план

В RCBD каждое воздействие встречается в каждом блоке, порядок внутри блока рандомизирован. Аддитивная модель: $y_{ij}=\mu+\tau_i+b_j+\varepsilon_{ij}$. При одном наблюдении на сочетание отдельное взаимодействие воздействия с блоком не оценивается; аддитивность — существенное предположение.

Допустим, две рецептуры липидных частиц приготовлены в четыре дня, по одной **новой партии каждой рецептуры** за день. Процент сохранённого вещества имеет значения `A = [83, 87, 78, 81]` и `B = [86, 89, 83, 85]`. Внутридневные разности `B − A = [3, 2, 5, 4]` процентных пункта дают средний эффект `3.5`, выборочное стандартное отклонение разностей $\sqrt{5/3}\approx1{,}29$ и стандартную ошибку среднего $1{,}29/\sqrt4\approx0{,}65$. Общий сдвиг обоих откликов в один день вычитается. Четыре дня дают **четыре парных сравнения**, а восемь партий — восемь приготовлений; технические повторы приборного определения не создадут дополнительных дней. Малое число блоков требует осторожности с интервалами и переносом результата на другие дни.

```python
import numpy as np
from scipy.stats import t

recipe_a = np.array([83, 87, 78, 81], dtype=float)
recipe_b = np.array([86, 89, 83, 85], dtype=float)
paired = recipe_b - recipe_a  # индексы соответствуют тем же дням
mean_diff = paired.mean()
se_diff = paired.std(ddof=1) / np.sqrt(len(paired))
ci = t.interval(0.95, df=len(paired) - 1, loc=mean_diff, scale=se_diff)
print(f"Средняя разность: {mean_diff:.2f} п.п.; SE: {se_diff:.2f}; "
      f"95% ДИ: [{ci[0]:.2f}, {ci[1]:.2f}] п.п.")
```

Интервал приблизительно `1.45–5.55` процентного пункта относится к **средней внутридневной разности для новых сопоставимых дней** при независимости дней и подходящей модели распределения разностей. С четырьмя днями проверка этой предпосылки слаба; вывод не распространяется автоматически на другое сырьё или режим хранения. Код ниже показывает расширение до трёх рецептур и восьми дней: блок включён в модель как категориальный фактор.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols

rng = np.random.default_rng(31)
rows = []
for block in range(8):
    block_effect = rng.normal(0, 2)
    for treatment in rng.permutation(["A", "B", "C"]):
        effect = {"A": 0, "B": 1, "C": 2}[treatment]
        rows.append((block, treatment, 10 + block_effect + effect + rng.normal(0, 0.5)))
blocked = pd.DataFrame(rows, columns=["block", "treatment", "y"])
fit_blocked = ols("y ~ C(treatment) + C(block)", data=blocked).fit()
print(sm.stats.anova_lm(fit_blocked, typ=2))
```

Здесь блоки учтены как фиксированные. При обобщении на популяцию случайно выбранных блоков рассматривают смешанную модель. Блокирование помогает, когда блок объясняет вариацию; оно не гарантирует уменьшения ошибки для любого разбиения.

В прикладной таблице сначала проверяют, что для каждого `block_id` действительно есть по одной записи каждой рецептуры и что время приготовления внутри дня не совпадает систематически с рецептурой. На графике показывают пары, соединённые **в пределах одного дня**, и распределение внутридневных разностей. Разброс самих дневных уровней не доказывает эффект рецептуры. Если отсутствует одна ячейка, не подставляют среднее за день: фиксируют причину пропуска и анализируют доступные наблюдения моделью, соответствующей фактическому плану.

## 7. Латинский квадрат и перенос эффекта

Латинский квадрат контролирует два блокирующих фактора: каждое воздействие появляется один раз в строке и столбце. Модель включает воздействие, строку и столбец, предполагая отсутствие существенных взаимодействий. Рандомизируют строки, столбцы и метки воздействий допустимым способом.

Пример размещения трёх рецептур по трём дням (строки) и трём позициям прибора (столбцы):

| День / позиция | 1 | 2 | 3 |
|---|---|---|---|
| 1 | A | B | C |
| 2 | B | C | A |
| 3 | C | A | B |

Каждая буква встречается по одному разу в каждом направлении. Но рецепт должен быть реально назначен **отдельному образцу** в каждой ячейке; девять последовательных отсчётов трёх уже приготовленных образцов не становятся девятью независимыми приготовлениями. Если порядок прибора влияет по-разному на рецептуры, взаимодействие невозможно просто «устранить квадратом», нужен другой план либо независимые повторы.

Греко-латинский план совмещает два ортогональных набора воздействий при двух направлениях блокирования и требует сильных предположений об отсутствии взаимодействий. Crossover имеет другую структуру: один объект получает воздействия во времени. В нём отдельно учитывают период, порядок, washout и возможный перенос эффекта (carryover).

## 8. Мини-проект и отчёт

Для своего эксперимента нарисуйте структуру объектов и повторов, определите фиксированные и случайные факторы, задайте формулу модели. На учебных данных оцените компоненты дисперсии и ICC, проверьте остатки и объясните, что даст дополнительная партия по сравнению с техническим повтором.

В отчёте нужны схема рандомизации, число независимых групп, обоснование ML/REML, сходимость, оценки дисперсий с неопределённостью и границы обобщения.

Для закрепления: [задания к лекции 7](07-homework.md) разбирают блочный опыт, псевдорепликацию и мощность на уровне партий. [Измерения частиц магнетита по ПЭМ](../experimental_analysis/data/tem_magnetite/README.md) дают иерархию «образец → снимок → частица», но число измеренных частиц не заменяет число независимых синтезов; известные ограничения набора нужно перенести в вывод. В отчёте отдельно назовите, какую новую партию или новый день следовало бы добавить, чтобы проверить самый важный вывод.
