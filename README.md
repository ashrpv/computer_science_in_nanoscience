# Компьютерные и информационные технологии в нанонауке

Курс для магистрантов и исследователей в нанонауке и материаловедении: от Python и экспериментальных данных до планирования исследований, моделей, машинного обучения и работы с данными производственного процесса.

## Цель

Научиться получать проверяемый результат из экспериментальных данных: описать дизайн, подготовить таблицы, выбрать модель, оценить неопределённость и воспроизвести расчёт. Курс использует Python. Основы статистики и ANOVA предполагаются изученными ранее; в прикладных темах разбираются необходимые предпосылки и типичные ошибки.

Оценивание строится преимущественно на мини-проектах. Итоговый проект связан с научной работой обучающегося либо с близкой темой, если собственные данные использовать невозможно.

Практические задания связывают методы с исследовательскими задачами. Учебные искусственные данные обозначены явно; реальные серии STA, вязкости, ПЭМ, микрофотографий и дифракции опубликованы с описанием происхождения и ограничений. В заданиях различаются точки одной кривой, частицы одного снимка, отдельные образцы и независимые синтезы. При наличии подходящих собственных данных студент может адаптировать проект к своей научной теме.

Слайды задают маршрут занятия, а конспекты объясняют промежуточные шаги, типичные ошибки и границы применения методов; в них есть дополнительные материалы, отсутствующие в презентациях. После чтения соответствующей темы попробуйте воспроизвести пример, объяснить смысл осей, единиц и независимой единицы, затем перейдите к связанному заданию. Примеры кода находятся внутри Markdown: сквозные блоки выполняйте в указанном порядке в отдельном notebook или `.py`-файле для каждой лекции; независимые фрагменты запускайте отдельно с нужными импортами. Искусственные данные обозначены явно. Примеры экспорта создают файлы в текущей рабочей папке, поэтому используйте отдельный каталог практики. Исходные приборные файлы сохраняйте отдельно.

## Среда

Для полного комплекта примеров используйте Python 3.11 или 3.12 и отдельное виртуальное окружение. Для первых конспектов по синтаксису и функциям дополнительных библиотек не требуется. В дальнейших темах используются NumPy, pandas, Matplotlib, Seaborn, SciPy, statsmodels, scikit-image, pybaselines и scikit-learn.

```bash
python -m venv .venv
```

Активируйте окружение: `source .venv/bin/activate` в Linux/macOS или `.venv\Scripts\Activate.ps1` в Windows PowerShell. Затем:

```bash
python -m pip install -r requirements.txt
```

[requirements.txt](requirements.txt) фиксирует версии библиотек для примеров курса. Jupyter при необходимости устанавливается отдельно: `python -m pip install jupyterlab`. В научном проекте дополнительно сохраняйте фактическую версию Python и полный состав своего окружения.
