# Компьютерные и информационные технологии в нанонауке

Учебные материалы по Python и обработке научных данных для нанотехнологий и материаловедения: лабораторные расчёты, планирование эксперимента, анализ спектров и изображений, моделирование.

## Цель и подход

Научиться получать проверяемый результат из экспериментальных данных: описать дизайн, подготовить таблицы, выбрать модель, оценить неопределённость и воспроизвести расчёт. Курс использует Python. Основы статистики и ANOVA предполагаются изученными ранее; в прикладных темах разбираются необходимые предпосылки и типичные ошибки.

Оценивание строится преимущественно на мини-проектах. Итоговый проект связан с научной работой обучающегося либо с близкой темой, если собственные данные использовать невозможно.

## Среда

Для полного комплекта примеров используйте Python 3.11 или 3.12 и отдельное виртуальное окружение. Для первых конспектов по синтаксису и функциям дополнительных библиотек не требуется. В дальнейших темах используются NumPy, pandas, Matplotlib, Seaborn, SciPy, statsmodels, scikit-image и pybaselines.

```bash
python -m venv .venv
```

Активируйте окружение: `source .venv/bin/activate` в Linux/macOS или `.venv\Scripts\Activate.ps1` в Windows PowerShell. Затем:

```bash
python -m pip install -r requirements.txt
```

[requirements.txt](requirements.txt) фиксирует версии библиотек для новых примеров. Jupyter при необходимости устанавливается отдельно: `python -m pip install jupyterlab`. В научном проекте дополнительно сохраняйте фактическую версию Python и полный состав своего окружения.
