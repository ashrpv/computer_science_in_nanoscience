# Информатика в нанонауке

Учебный проект, объединяющий основы программирования на **Python** с задачами из области нанотехнологий и наноматериаловедения: моделирование и анализ наночастиц, симуляция аналитических приборов и другое.

## Цель

Научить использовать python для решения практических задач из научной работы: лабораторные расчёты, обработка данных спектрометра, контроль параметров синтеза и моделирование нанообъектов.

## Структура репозитория

```
computer_science_in_nanoscience/
├── README.md                     # этот файл
└── python_basics/                # модуль: основы Python
    ├── README.md                 # описание модуля
    ├── 01-memo.md                # конспект-шпаргалка по основам Python
    ├── 01-first_homework.md      # домашнее задание №1 (10 задач)
    └── example.py                # простой пример кода
```

## Модули

| Модуль | Содержание |
|---|---|
| [`python_basics/`](python_basics/README.md) | Основы Python: типы данных, строки, списки, словари, множества, кортежи, условия, циклы, функции, comprehensions |

## Как пользоваться

1. Изучите конспект [`python_basics/01-memo.md`](python_basics/01-memo.md) — по одному разделу за раз.
2. Выполните задания из [`python_basics/01-first_homework.md`](python_basics/01-first_homework.md), создавая собственные `.py`-файлы.
3. Проверяйте решения в Python-интерпретаторе или в редакторе с поддержкой Python.

## Требования

- **Python 3.7+** (отдельные темы опираются на возможности 3.10+)
- Дополнительные библиотеки не требуются — всё работает на стандартной библиотеке

## Статус

Проект в разработке. Планируются модули по работе с данными (NumPy, Pandas), визуализации и обработке экспериментальных результатов.
