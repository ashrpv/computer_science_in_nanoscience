# STA железосодержащих материалов: учебный набор

11 экспериментальных выгрузок NETZSCH STA 449 F5, 82 325 отсчётов. Набор предназначен для обучения обработке DSC/TG, проверке сопоставимости опытов и планированию следующего измерения. **Это 11 прогонов, а не 82 325 независимых опытов.** Исходные образцы и подготовка не документированы достаточно подробно для причинного вывода о фазе, влиянии матрицы или кинетических параметрах.

| Прогоны | Роль | Ограничение |
|---|---|---|
| 198, 201 | Нитрат, номинально 15 и 25 K/мин | Разные прогоны; метаданные 198 конфликтуют с названием |
| 200, 202 | Сульфат, номинально 15 и 25 K/мин | Степень окисления и гидратация 202 не подтверждены |
| 197 | SiO₂ + нитрат, 15 затем 5 K/мин | Неясен смысл «повторный»; граница сегментов |
| 105, 106, 107, 108 | Историческая матричная серия в Al | Разные составы, программы, атмосферы/предыстория |
| 028, 043 | Fe₃O₄ и Fe₃O₄@SiO₂ | Экспортированы разные сегменты/диапазоны; 043 содержит DSC(subtr.3) |

## Файлы и запуск

- [`raw/sta_NNN.csv`](raw/sta_198.csv): **обезличенный** приборный экспорт в UTF-8; многострочная шапка, разделитель `;`, десятичная запятая (028: точка). Все строки числового блока исходного файла сохранены без правки, включая разрядность и порядок.
- [`processed/sta_NNN.csv`](processed/sta_198.csv): прямоугольная таблица в UTF-8, запятая-разделитель и десятичная точка, пустая ячейка означает отсутствие канала. Числа представлены исходными десятичными строками без округления, сглаживания, удаления точек или перенормировки.
- [`manifest.csv`](manifest.csv): числа строк, приборные поля, каналы, SHA-256 исходно предоставленного файла, опубликованного raw и обработанного CSV. Исходный хеш служит только для сверки с оригиналом, который публично не хранится.
- [`data_dictionary.md`](data_dictionary.md) и [`issues.csv`](issues.csv): единицы, решения и нерешённые вопросы. `prepare.py` повторно создаёт processed CSV из опубликованных raw CSV.

```bash
python datasets/sta_iron_oxides/prepare.py
python -m unittest discover -s datasets/sta_iron_oxides/tests -v
```

Для анализа: `pd.read_csv('datasets/sta_iron_oxides/processed/sta_198.csv', dtype={'run_id':str})`. Для загрузки raw сначала найдите строку `##Temp./°C;`, сохраните остальные строки шапки как метаданные и читайте числовой блок с `sep=';'` и `decimal=','` (028: `'.'`). Не сортируйте целый прогон по температуре: выдержки и охлаждение должны оставаться в порядке измерения. В нескольких записях нет TG; пустое значение массы не означает неизменную массу.

## Происхождение и обезличивание

Исходные 11 файлов предоставлены автором курса. Их байты в `raw/` перекодированы из CP1251 в UTF-8, а значения строк `#FILE`, `#OPERATOR`, `#LABORATORY` заменены нейтральными кодами; остальные заголовки и *все строки числового блока* сохранены. Имя исходного файла не публикуется, чтобы не раскрывать имя участника в названии двух измерений; сопоставление выполняется по номеру прогона и хешу в manifest. Календарные даты и коды образцов сохранены для оценки сопоставимости. Преобразование `prepare.py` меняет только структуру таблицы и десятичный разделитель; она не корректирует DSC и TG.

Одинаковый номер не гарантирует физическую тождественность между сериями; «M8», «П8» и «П1» не объединяются по названию. `SAMPLE`, `MATERIAL` и `IDENTITY` воспроизведены как отдельные приборные поля; см. журнал противоречий. Тепловое событие обнаруживают по DSC независимо от TG, а фазу проверяют структурным методом, например дифракцией на образцах после прерывания нагрева.
