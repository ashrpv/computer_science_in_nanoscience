# Комплексные задания по экспериментальному плану и регрессии

Девять небольших серий по наноматериалам и дисперсным системам перенесены из ранее применявшегося учебного задания «Задание-2 — Регрессия — старое». Исходный документ был предоставлен автором курса; в репозиторий включены текстовые таблицы CSV, а не исходный DOCX. Это **исторические учебные таблицы с неполными метаданными**: из них не следует автоматически, что каждая строка представляет независимый синтез или что повторные значения получены на разных партиях.

Начните с [условия практикума](assignment.md), затем откройте [словарь и журнал неоднозначностей](data_dictionary.md). Для быстрой проверки целостности таблиц выполните `python projects/regression_cases/verify.py` из корня репозитория; дополнительных пакетов скрипту не требуется. Исходные значения CSV не следует заменять «исправленными» без отдельного протокола изменений.

Файл 2 сохраняет исходные записи как строки с суффиксом `_raw`: одни и те же условия занимают несколько строк при разных временах отжига, а отдельные поля заполнены текстом. Для файла 6 **«Не-керосин» не раскрыт до конкретного вещества**. В файле 4 неизвестны единицы двух концентраций и смысл отклика. Вопросы научной интерпретации требуют журнала синтезов или оригинальной публикации; код не может восстановить их из таблицы.

## Как практикум связан с курсом

- Выбравшие **полный практикум** после [лекций 5–7](../../experimental_design/06-homework.md) проводят аудит происхождения, единиц, факторного плана и повторов без подгонки сложной модели.
- После [лекций 11–12](../../machine_learning/11-homework.md) они выполняют регрессионную часть на варианте **3 или 6** и краткий аудит ещё одного варианта. Разбиение означает только тот сценарий новых данных, который реально представлен в серии. Этот полный практикум можно выбрать как отдельный трек вместо блока реальных материалов [задания 12](../../machine_learning/12-homework.md); при недоступном Kaggle там же описана более короткая локальная замена одного трека.
- Для итогового проекта студент может использовать проверенную собственную серию вместо этих исторических таблиц. Здесь нельзя показать независимую проверку на новых партиях, поскольку сквозных идентификаторов партий и кампаний нет.

## Происхождение опубликованных примеров

В старом задании варианты 7–9 соотнесены с исследованиями: Ba-Abbad и соавт., [ZnO методом золь-гель](https://www.sciencedirect.com/science/article/pii/S0925838812016507); Katata-Seru и соавт., [наноэмульсия чесночного масла](https://www.sciencedirect.com/science/article/abs/pii/S0167732217334293); Tajik и соавт., [стабилизация эмульсий кремнезём-графеновым наногибридом](https://www.sciencedirect.com/science/article/abs/pii/S0167732216306328). CSV воспроизводят **предоставленный учебный документ**; построчное совпадение с опубликованными статьями здесь не установлено. При цитировании экспериментальных результатов студент сверяет таблицу с первоисточником и указывает источник, использованный им фактически. Для вариантов 1–6 исходный документ не называет источников, поэтому их происхождение и воспроизводимость нельзя считать документированными.
